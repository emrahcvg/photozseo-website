# Legacy categoryId Haritası — Paylaşılan Veri Artefaktı + Doğrulama (Alt-proje #5, standalone kısım)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eski elle yazılmış nokta-id'leri (örn. `electronics.phones`) Google sayısal ID'sine eşleyen **tek kanonik veri dosyası** `legacy-map.json`'u üretmek; saf bir `mapCategoryId()` yardımcı fonksiyonu (`uncategorized` fallback + idempotency) yazmak; ve haritadaki her Google id'nin `tree.json`'da var olduğunu doğrulayan **CI hard-stop testini** kurmak. Bu artefakt'ı hem #3 (web render) hem #4 (iOS bundle) tüketir.

**Scope sınırı (ÖNEMLİ):** Haritanın **okuma-zamanı uygulaması** (getStore sonrası lazy çeviri, `onRequestPut` write-normalize, render gruplaması) #3 web-render planının kapsamındadır ve render ile atomik gider — bu plan onları **tekrarlamaz**. Bu plan yalnızca paylaşılan veri dosyası (`legacy-map.json`), onu okuyan saf helper, ve doğrulama testlerini üretir. Böylece #3 ve #4 aynı dosyayı/aynı helper davranışını tüketebilir.

**Architecture:** Saf TS modülü (`legacy-map.ts`) `legacy-map.json`'u import edip `mapCategoryId(oldId)` saf fonksiyonunu dışa verir. İki vitest test dosyası: (1) fallback + idempotency davranış testi (bağımsız, her zaman koşar); (2) `tree.json`'a karşı kapsama testi (CI hard-stop, **#1 build çıktısına bağımlı**). Numeric Google ID kanonik anahtardır; `tree.json` düğüm id'leri **string**'tir (örn. `"267"`), dolayısıyla `legacy-map.json` hedefleri de string tutulur.

**Tech Stack:** TypeScript, Node 22 ESM, vitest 3, Astro repo (`npm run test` → `vitest run`).

```typescript
import legacyMap from '../taxonomy/legacy-map.json';

export const UNCATEGORIZED = 'uncategorized' as const;

type LegacyMapFile = {
  version: number;
  map: Record<string, { googleId: string; googlePath: string }>;
};

const MAP: Record<string, string> = Object.fromEntries(
  Object.entries((legacyMap as LegacyMapFile).map).map(
    ([oldId, v]) => [oldId, v.googleId],
  ),
);

/** Saf sayisal string mi? (Google id'ler "267", "1604" gibi.) */
export function isGoogleId(id: string): boolean {
  return /^[0-9]+$/.test(id);
}

/**
 * Eski categoryId'yi Google sayisal id'ye cevirir (saf, yan etkisiz).
 * - undefined/null/bos -> UNCATEGORIZED
 * - zaten Google id (saf sayisal) -> oldugu gibi (idempotent)
 * - haritada var -> googleId
 * - haritada yok (serbest id) -> UNCATEGORIZED (sessiz kayip yok; cagiran taraf raporlar)
 */
export function mapCategoryId(oldId: string | null | undefined): string {
  if (oldId == null || oldId === '') return UNCATEGORIZED;
  if (isGoogleId(oldId)) return oldId;
  return MAP[oldId] ?? UNCATEGORIZED;
}
```
