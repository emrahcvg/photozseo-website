地元生産者の製品をオンラインでリストするには、自治体はカメラを必要とする前に 3 つのことが必要です。それは、共通のビジュアル標準、すべての生産者が記入する製品情報フォーム、およびファイル命名規則です。これらを導入すれば、保存瓶が 12 個入った女性協同組合と 2 種類のチーズを入れた家族向け乳製品会社が同じカタログに収まり、一貫した地域向け商品の一部のように見えるようになります。これらがなければ、40 の異なる背景、40 の命名習慣、そして誰にも比較できないリスト ページが得られます。

*最終確認日: 2026 年 11 月。これは実用的な写真と出品ガイドです。これは法的アドバイスではなく、地方自治体の販売、入札、調達の規則について説明するものではありません。独自の法律に従ってください。マーケットプレイスの画像ルールは変更されるため、出品する各プラットフォームの現在のガイドラインを確認してください。*

## 複数の生産者のカタログにおける実際の問題は何ですか?

以下のシナリオは、作品の形を示すための仮説です。ある地区の自治体は、女性協同組合 (ジャム、ピクルス、乾燥ハーブ)、2 人の蜂蜜飼育員、オリーブオイル絞り機、手工芸品グループ (織布袋、フェルト)、およびいくつかの小さなパン屋など、35 の生産者と協力して地場産品プログラムを運営しています。彼らはオンラインでの存在を 1 つだけ望んでおり、希望者には地域または全国の市場への上場も望んでいます。

典型的な障害は予測可能です。

- 各プロデューサーは、異なる背景と光を備えた携帯電話の写真を送信します
- 商品名は4通り表記（「タイム」、「乾燥タイム50g」、「ケキック」、「KEKIK 50 GR」）
- 同じ商品がページ間で異なるウェイトで表示されます
- 写真には `IMG_2231.jpg` という名前が付けられていますが、誰のものなのかは誰も知りません。

## ステップ 1: 1 ページのビジュアル標準を作成する

組合員が訓練を受けずに理解できる 1 ページにまとめてください。

| ルール | 標準（例、独自に調整） |
|---|---|
| メイン画像 | 製品全体、無地の明るい背景、中央に配置、フレーム内に他に何もない |
| 2番目と3番目の画像 | 原材料を記載した裏ラベル、テクスチャーまたは工芸品の詳細のクローズアップ |
| ライフスタイルイメージ | 1 つのオプションのシンプルな設定、すべてのプロデューサーに同じスタイル |
| ライト | 窓の日光または 2 つの柔らかいランプ、フラッシュなし |
| 向き | すべてのメイン画像のアスペクト比を同じにする（一度決定） |
| 小道具 | 使用方法（蜂蜜用スプーン）を説明する場合のみ、他のブランドでは使用しないでください |
| ロゴとテキスト | ウォーターマークは追加されていません。製品ラベルにはそれが何を示しているかが示されています |
| レタッチ中 | 明るさとトリミングのみを修正します。製品の色や形を変えないでください |

使用する予定の最も厳密なマーケットプレイスを確認してアスペクト比を選択し、より大きなマスターを保持します。記事の数字に頼るのではなく、そのプラットフォームの現在の画像ページで数字を確認してください。

## ステップ 2: 写真を撮る前に製品に関する事実を収集する

写真と文章は別々に作るとうまくいきません。共有シートを使用します (スプレッドシートが機能します)。

| カラム | なぜそれが重要なのか |
|---|---|
| プロデューサーコード | 短い安定した ID。ファイル名のプレフィックスになります |
| 製品名 (必要に応じて現地言語とその他の言語 1 つ) | 写真のラベル、シート、リストに同じ文言が記載されている |
| 正味重量または体積 | 写真のパックと一致する必要があります |
| 成分・材質 | リストに掲載するために必要です。ラベルの一致も確認してください |
| 変異体 | 味、大きさ、色 |
| 出身地・村 | 地域のストーリーをサポートします |
| 生産者が保有する認証または登録 | プロデューサーが文書化できるもののみをリストします |
| 人物の写真撮影の同意 | プロデューサーまたはワークショップの画像に対するはい/いいえ |

生産者が証明できない主張をリストに記載しないでください。製品に地理的表示またはオーガニックステータスが登録されているかどうかは、カタログではなく生産者自身の文書によって決定されます。

## ステップ 3: 共有写真の日を実行する

この種の番組の場合、通常、各プロデューサーに単独で撮影を依頼するよりも、地区ごとに 1 回の「写真撮影日」を設けたほうが効率的です。

1. 窓の近くに無地の背景と三脚を備えたテーブルを 1 つ設置します。
2. 写真リストを印刷します: フロント、バックラベル、詳細 1 枚、必要に応じて使用中の 1 枚。
3. 各バッチの最初のフレームに番号カード (生産者コード) を入れておくと、バッチを簡単に分類できます。
4. 各生産者の商品を一緒に撮影します。同じカメラ距離を保ちます。
5. 最後に、プロデューサーが帰る前にラップトップまたはタブレットで簡単なレビューを行い、その場で再度写真を撮ります。

大きな工芸品や生鮮品など、輸送できない品目の場合は、訓練を受けたボランティアまたはスタッフが同じキットを持って訪問できます。

## ステップ 4: ファイルに名前を付けて整理する

命名規則により、数時間後の時間を節約できます。

| 柄部分 | 例 |
|---|---|
| プロデューサーコード | `p014` |
| 製品 | `olive-oil` |
| サイズ/バリエーション | `500ml` |
| ビュー | `front`、`label`、`detail` |
| フルネーム | `p014-olive-oil-500ml-front.jpg` |

小文字、ハイフン、スペース、特殊文字は使用しないでください。わかりやすいファイル名は、自分のサイトの検索エンジンにも役立ちます。

## ステップ 5: 製品カードだけでなく、生産者プロフィールを作成する

地域産品のバイヤーはストーリーを買うことが多い。製品画像を統一し、プロフィール カードにアイデンティティを記載します。

- 生産者または協同組合の名前と場所
- 2文か3文の短い物語
- 同意された肖像画またはワークショップの画像
- プロデューサーが選択したリンクまたは連絡ルート

人物の写真については必ず同意を求め、公開する連絡先の詳細を各プロデューサーと決定してください。

## カタログの発行前チェックリスト

- [ ] すべてのプロデューサーに共有される 1 ページのビジュアル標準
- [ ] すべての製品にはファクトシートの行があります
- [ ] 重量、名前、バリアントがパック、シート、リスト間で一致します。
- [ ]メイン画像の占有率、背景、フレーミング
- [ ] ファイル名は規則に従います。 `IMG_`の残り物はありません
- [ ] あらゆる人物の画像に記録される同意
- [ ] 本文中に証明不可能な主張 (オーガニック、原産地保護、健康) は含まれていません
- [ ] プラットフォーム イメージ ルールがライブ プラットフォーム ページで再読み取りされる
- [ ] 法務部門は自治体の参加方法を確認した
