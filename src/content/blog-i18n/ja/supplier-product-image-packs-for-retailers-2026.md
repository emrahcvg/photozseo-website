サプライヤー イメージ パックは、SKU ごとに整理されたダウンロード可能な製品写真のセットで、どの写真がどの製品に属するかを示すデータ ファイルと、再販業者がそれらをどのように使用するかについての短いメモが含まれています。パックを店舗や市場に直接積み込むことができる小売業者は、商品をより早く出品し、間違いが少なく、再注文する可能性が高くなります。このガイドでは、実際的なパック構造、命名規則、サイズ階層、使用上の注意、およびそれをまとめる CSV について説明します。

*最終確認日: 2026 年 11 月。チェックした出典: 米国著作権局 (著作権 FAQ)、Shopify ヘルプ センター (CSV ファイルを使用した製品のインポートおよびエクスポート)、ICC (インコタームズ 2020 規則ページ)。

## 小売業者がイメージ パックを求める理由

たとえば、300 SKU のキッチン用品を扱うサプライヤーを想像してください。 20 の小売業者がそれぞれ、シーズンごとに同じメールを送信します。「新色の写真を送ってもらえますか?」 「24cmパンはどのヤスリですか？」写真の蓋は付属しますか？サプライヤーは、共有ドライブのリンク、IMG_4821.jpg などのファイル名、フォルダーとは異なる順序での価格表を返します。

その後、小売業者は何時間もかけて写真と列を手作業で照合します。間違いはほぼ確実に発生します。間違ったリストで間違った色を選択したり、SKU に含まれていないアクセサリーを付けて撮影したセットや、2 つの商品の下に同じ写真をアップロードしたりするなどです。パックはその作業を取り除き、製品を最もよく知っている一方の当事者であるサプライヤーに移します。

## パックの内容

| アイテム | それは何ですか | 小売業者がそれを必要とする理由 |
|---|---|---|
| SKUの写真 | SKU ごとに 1 つのフォルダー、またはすべてのファイル名に SKU が含まれる 1 つのフラット フォルダー | 迅速なインポートと推測の必要なし |
| 商品データCSV | SKU ごとに 1 行: 名前、バーコード、色、サイズ、画像ファイル名 | 写真を製品および価格表にマッピングします |
| 使用権に関する注意事項 | 1 ページ: 再販業者ができることとできないこと | 許可の質問を削除します |
| お読みください | 命名ルール、サイズ階層、パック日付 | 新入社員だけでパックを利用できるようにする |
| 変更ログ | 前回のパック以降に追加または置き換えられたもの | 小売業者は変更された部分のみを更新します |

最初のバージョンは小さいままにしておきます。ベスト 50 SKU をカバーし正確なパックは、半分古い完全なアーカイブよりも役立ちます。

## 小売業者が並べ替えおよび検索できる命名規則

ファイルごとに 1 つのパターンを使用し、それを Readme に記述します。シンプルで読みやすい形式は、SKU、ビュー コード、オプションのカラー コードです。

- SKU-12345_front.jpg
- SKU-12345_side.jpg
- SKU-12345_バックレッド.jpg
- SKU-12345_詳細ハンドル.jpg

守るべきルール: 小文字、数字、ハイフン、アンダースコアのみ。アップロード システムやオペレーティング システムによってはスペースやアクセント記号が適切に処理されないため、スペースやアクセント記号は使用できません。名前に「final」、「new」、または「copy」は含まれません。 SKU が名前の先頭にあるため、ファイルは隣り合って並べ替えられ、簡単な検索で価格表と照合できます。

検索エンジンの場合、わかりやすいファイル名が役に立ちますが、サプライヤー パックはソース ファイルです。多くの小売業者は、公開時に名前を独自のキーワード名に変更します。 [SEO用に商品写真に名前を付ける方法](/ja/blog/how-to-name-product-photos-for-seo) に関するガイドでは、その 2 番目のステップがどのようなものかを示しているため、クリーンな SKU ベースのオリジナルが最良の出発点である理由がわかります。

## サイズ階層: マスター、ウェブ、サムネイル

マーケットプレイスでは画像ルールが変更されるため、1 つのファイルをすべてのプラットフォームに事前に適合させようとしないでください。代わりに、各写真にいくつかの階層を付けて、その写真がどこから来たのかを小売業者に伝えます。以下の数値は推奨される開始セットであり、プラットフォーム要件ではありません。

| 階層 | 推奨される使用方法 | 推奨仕様 (サプライヤーの選択) |
|---|---|---|
| マスター | アーカイブと再トリミング | オリジナルまたは高解像度の JPEG または PNG、強力な圧縮なし |
| ウェブ | ショップとほとんどのマーケットプレイス | 正方形のキャンバス、長辺約 2000 ピクセル、JPEG |
| サムネイル | リスト、見積書、カタログ | 長辺で約600ピクセル |

小売業者が特定のプラットフォームで販売していることがわかっている場合は、そのプラットフォームに合わせたサイズのフォルダーを追加します。まず、各プラットフォームの現在の販売者ガイドラインを確認してください。いくつかのマーケットプレイスが期待しているものについては、[マーケットプレイスの画像サイズ](/ja/marketplace-image-sizes) を参照してください。ピクセル値は変化するため、ページはピクセル値が永続的であることを保証するのではなく、ピクセル値の取得元にリンクします。

## 写真の一貫性は解像度よりも重要です

異なる日に異なる光で撮影されたパックは、たとえすべてのファイルが鮮明であっても、小売店のページでは見栄えが悪くなります。撮影する前に、背景 (白またはライトグレー、全範囲で同じ)、カメラアングルセット (正面、側面、背面、ディテール、スケールなど)、およびフレームの 3 つを修正します。これにより、製品がフレームの同じ割合を占めるようになります。三脚または固定距離を使用してください。また、角度が固定されているため、小売店が「もう 1 枚」と尋ねるのを防ぐことができます。

バリエーションの場合は、すべての色を同じ位置で撮影し、カラーコードで名前を付けます。 1 つの色を撮影して、エディターで変更するように小売店に指示しないでください。

## 使用権注意事項

写真は作成された瞬間から著作権によって保護されます。米国著作権局の FAQ によれば、作品は、具体的な形で作成され固定されると保護され、登録は任意であるとされています。つまり、小売業者はあなたのファイルを無料で使用できると安全に想定することはできず、優良な小売業者は尋ねるでしょう。事前に短いメモで回答します。

通常、メモには次の内容が含まれており、自分の言葉で書かれ、あなたの国の弁護士によってチェックされます。

1. 写真の所有者 (あなた、またはあなたにライセンスを取得した写真家)。
2. それらを使用できるのは誰ですか (製品を在庫している限り、認定再販業者)。
3. どこ（自分のショップ、マーケットプレイス、ソーシャル投稿、印刷されたカタログ）。
4. 変更される内容 (サイズ変更、トリミング、名前変更。ただし、誤解を招くテキストや他のブランドのロゴは追加しないでください)。
5. 関係が終了した場合はどうなりますか (妥当な期間内に画像を削除します)。

これはコミュニケーションツールであり、法的アドバイスではありません。写真に写真家の作品、モデル、または他人のブランドが含まれている場合は、まずご自身の権利を確認してください。

## すべてをつなぐCSV

CSV は小売業者が最も価値を置く部品です。 SKU ごとに 1 行、列は固定順序です。実用的な最低限度:

| カラム | 例 |
|---|---|
| スク | SKU-12345 |
| バーコード | 製品の EAN または UPC (ある場合) |
| 製品名 | 使用したい名前 |
| 色、サイズ | バリアントフィールド |
| 画像メイン | SKU-12345_front.jpg |
| 画像_2から画像_6まで | 他のビューファイル |
| パック_バージョン | 2026-11 |

小売業者が Shopify を使用している場合、これは製品 CSV に自然にマッピングされます。 Shopify ヘルプセンターによると、製品 CSV には製品画像の URL、画像の位置、画像の代替テキスト、および別のバリアント画像 URL の列があり、Shopify はインポート中にパブリック URL から画像をダウンロードしてストアに再アップロードします。 alt テキスト フィールドには最大 512 文字を入力できますが、Shopify では 125 文字以下に抑えることをお勧めします。 Web 層をパブリック アドレスにアップロードし、URL を CSV に追加すると、小売業者は製品範囲全体を一度にインポートできます。パートナーに列名を約束する前に、Shopify の現在のページを読んでください。 [Shopify CSV と API](/ja/blog/shopify-csv-vs-api-2026) でのインポート方法の比較は、どのルートを文書化するかを決定するのに役立ちます。

卸売条件も提供する場合は、HS コードと原産国を別の貿易データ タブに含めます。小売業者または通関業者はこれらを国境を越えた注文に使用するため、資格のある専門家に正しい分類を確認する必要があります。

## 実際に動作するワークフローの例

上記の 300 SKU サプライヤーの週次ルーチンの例:

1. 新しい製品または変更された製品を固定セットアップで撮影します。
2. SKU ルールを使用して元の名前を変更します。
3. 3 つの層をパック フォルダーにエクスポートします。
4. CSV 行とパックのバージョンを更新します。
5. テスト: CSV を開き、ランダムに 5 行を取得し、各ファイル名がフォルダー内に存在することを確認します。
6. パックを 1 つの共有リンクに公開し、小売業者に 2 行の変更ログを電子メールで送信します。

ステップ 5 は、ほとんどのサプライヤーがスキップするステップであり、ほぼすべてのエラーが検出されます。

## パックを送る前のチェックリスト

- [ ] 価格表の各 SKU には、パック内に少なくとも 1 枚の写真が含まれています。
- [ ] すべてのファイル名はルールに従い、スペースは含まれません。
- [ ] CSV 内のすべてのファイル名が存在し、その逆も存在します。
- [ ] 背景とアングルのセットは範囲全体で一貫しています。
- [ ] サードパーティのロゴ、透かし、ライセンスのないモデルは表示されません。
- [ ] 使用権に関するメモとバージョンの日付はパックに含まれています。
- [ ] 不足している写真が必要な小売店向けに、1 行の連絡先が含まれています。

## photoZseo が適合する場所

独自の製品を撮影する場合、photoZseo iPhone および iPad アプリには、ビューの一貫性を維持するための 7 つの角度を備えたテンプレート カメラがあり、46 のマーケットプレイス向けに写真のサイズ変更と圧縮を行い、ファイル名を変更して CSV、XLSX、または JSON をエクスポートできます。小売業者からの要求に応じて、B2B PDF 見積書を作成することもできます。アプリについては [ダウンロードページ](/ja/download) を参照してください。 Chrome 拡張機能は、製品ページから写真と製品データを収集し、ZIP、CSV、または Excel にエクスポートします。これは、製品ページがすでにデータを保持している場合に役立ちます。現在のプランについては、[価格設定](/ja/pricing) を確認してください。

photoZseo は、使用する権利がある画像に対してのみ使用してください。マーケットプレイス名は互換性のみを表します。 photoZseo は、どのマーケットプレイスとも提携または承認されていません。
