製品の一括アップロードとは、各リストを手動で作成するのではなく、製品ごとに 1 行のスプレッドシート (CSV または XLSX) を準備し、それを 1 回アップロードすることを意味します。 eBay、Shopify、Amazon、および Trendyol はこれをサポートします。 Etsy では、新しいリストを一括作成することはできません。ほとんどの失敗を引き起こす 2 つのルールはどこでも同じです。テンプレートのヘッダーを指定されたとおりに保つことと、すべての画像を公開の直接 URL として指定することです。

*最終確認日: 2026 年 11 月。チェックしたソース: Shopify ヘルプ センター、「CSV ファイルを使用して製品をインポートおよびエクスポートする」。 eBay セラー ハブのヘルプ、「出品を一括作成」 (セラー ハブ レポート > アップロード)。 Etsy ヘルプ センター、「一度に複数のリストを作成または編集できますか?」; Amazon Seller Central ヘルプ、「インベントリ ファイル テンプレート」および「イメージの問題」(検索の抜粋からお読みください。以下の注を参照)。 Trendyol Akademi Satıcı Bilgi Merkezi、「Excel Ürün Girişi」および「Ürün Görseli Seçimi ve Yükleme」（検索抜粋により読み取り）。*

## 各プラットフォームは一括アップロードをどのように処理しますか?

| プラットフォーム | 一括作成しますか? | どこ | ファイルの種類 | 画像ルール |
|---|---|---|---|---|
| Shopify | はい | 製品 > 輸入 | CSV、UTF-8、カンマ区切り | パブリック https:// URL |
| eBay | はい | 販売者ハブ > レポート > アップロード > テンプレートの取得 | CSV または XLSX | https:// URL、リスティングごとに最大 12 個、\ で区切る |  |
| Amazon | はい | アップロードによる製品の追加 (Seller Central) | カテゴリ固有のインベントリ ファイル テンプレート | 直接 URL。リダイレクトとポップアップは拒否されます |
| Trendyol | はい | 製品 > バルク製品操作 > Excel 製品入力 | Excel、カテゴリごとに 1 つのテンプレート | 画像リンク欄のリンク |
| Etsy | いいえ (編集のみ) | ショップマネージャー > リスト | 適用できない | 適用できない |

## Shopify に商品を一括アップロードするにはどうすればよいですか?

Shopify のヘルプ センターは形式を設定します。最初の行は列ヘッダーである必要があり、列はカンマで区切られ、ファイルは行末が LF の UTF-8 である必要があります。新しい製品の場合は、`Title` のみが必要です。バリアントを使用する場合は、`URL handle` も必要です。 SKU などのバリアント列にも `Option1 name` と `Option1 value` が必要です。それ以外の場合、Shopify はデフォルトのバリアントを作成し、更新時に既存のバリアントを削除します。

画像は、パスワード保護なしでパブリックにアクセス可能な `https://` URL である必要があります。 Shopify はインポート中にこれらをダウンロードするため、後で削除できます。画像ファイル名はアップロード後に編集できません。また、`_thumb`、`_small`、または `_medium` のサフィックスを含めることはできません。ビデオと 3D モデルは CSV ではサポートされていません。

| 限界 | 値 (Shopify ヘルプセンター) |
|---|---|
| 製品ごとのオプション | 3 |
| 商品ごとの画像 | 250 |
| 製品ごとのタグ | 250 |
| 代替テキスト | 最大 512 文字、125 文字以下を推奨 |
| SEOタイトル | 70文字 |
| SEOの説明 | 320文字 |

同じページからの既知の障害の原因: `Barcode` 列と `Barcodes` 列の両方を含むファイルで障害が発生します。パックディメンション列の部分セットは失敗します。上書きをオンにすると、空白セルは既存の値を消去します。 API ルートとの詳細な比較については、「[Shopify CSV と API](/ja/blog/shopify-csv-vs-api-2026)」を参照してください。

## 出品情報を eBay に一括アップロードするにはどうすればよいですか?

eBay の現在のツールは Seller Hub Reports です。 [アップロード] に移動し、[テンプレートの取得] をクリックして、リストのソースとファイルの種類を選択します。 XLSX がデフォルトであり、上級販売者には CSV が推奨されます。 XLSX ダウンロードには、最大 10 個のカテゴリをそれぞれ独自のシートに含めることができます。完成したファイルをアップロードすると、eBay は指定どおりに項目をリストします。

リストを追加するための必須フィールドには、アクション、カテゴリ ID、タイトル (最大 80 文字)、形式、期間、開始価格、数量、条件 ID、説明、商品写真の URL が含まれます。米国のサイトでは、一致する商品固有の列に UPC (または同等のもの) が必要であり、書籍カテゴリには ISBN が必要です。

画像の URL は、`https://` で始まり、`.jpg` または `.png` などのファイル拡張子で終わり、2048 文字以内で、スペースを `%20` に置き換える必要があります。パイプ (`|`) 文字で区切って、1 つのリストにつき最大 12 個の画像をリストできます。画像は自己ホストすることも、eBay Picture Services でホストすることもできます。バリエーションの場合、親行は数量と価格を空のままにし、各子行には独自の行があります。

## Amazon に商品を一括アップロードするにはどうすればよいですか?

Amazon は、Seller Central の [アップロードによる製品の追加] ページから生成されたカテゴリ固有の在庫ファイル テンプレートを使用します。まだカタログにないアイテムの場合は、属性を必須、条件付き必須、または推奨としてマークする製品テンプレートを使用します。すでにカタログにあるアイテムについては、製品 ID で検索し、事前に入力されたファイルを使用できます。アップロード後、一致するファイルの種類を選択し、各 SKU の処理レポートを確認します。

画像については、Amazon の「画像の問題」ヘルプ ページには、ポップアップ URL またはリダイレクト URL は受け入れられず、アップロードは処理されないため、URL は画像ファイルを直接指す必要があると記載されています。メニュー パスと受け入れられるファイルの種類はマーケットプレイスの地域によって異なるため、ダウンロードしたテンプレートの指示に従ってください。画像の寸法については、[Amazonの商品写真のスペック](/ja/blog/amazon-product-photo-specs-2026) を参照してください。

## Etsyに一括アップロードできますか?

新規出品には対応しておりません。 Etsy のヘルプセンターには、新しいリストを一括アップロードできないと記載されており、リストを 1 つ作成してコピーすることを推奨しています。タイトル、タグ、説明、価格、カスタム オプション、処理プロファイル、配送プロファイルなど、既存のリストをショップ マネージャーから一括編集できます。 Etsy リスティングを一括作成すると主張するツールはサードパーティ製品であり、Etsy 機能ではないため、その規約と API アクセスをご自身で確認してください。

## Trendyol に商品を一括アップロードするにはどうすればよいですか?

販売者パネルで、[製品]、[バルク製品操作] の順に開き、Excel の製品入力オプションを使用します。 Trendyol の販売者情報センターでは、カテゴリ コードとアップロード タイプ「Yeni Ürün Ekle」（新製品の追加）によって識別される、カテゴリごとに 1 つのテンプレートについて説明します。画像は画像リンク (Görsel Linki) 列にあります。 Trendyol はギャラリー メソッドについても文書化しています。まず、製品バーコードと同じファイル名 (複数の画像の場合は barcode_1、barcode_2) を付けて画像をイメージ ギャラリーにアップロードし、次にそれらの名前を列にコピーします。アップロードする前にテンプレートの形式を変更しないでください。

パネルの文言は変更される可能性があるため、自分の販売者アカウント内のテンプレートと照合して手順を確認してください。 Trendyol および Hepsiburada のイメージ ルールについては、「[トレンディオールとヘプシブラダの製品写真](/ja/blog/trendyol-hepsiburada-product-photos)」を参照してください。

## 最も一般的な一括アップロード エラーは何ですか?

1. ヘッダーを編集または名前変更しました。テンプレートはヘッダー テキストと一致します。翻訳したり並べ替えたりしないでください。
2. カテゴリ テンプレートが間違っています。 Amazon、eBay、Trendyol テンプレートはカテゴリごとに異なります。
3. 直接ではない画像 URL。 Web ページ、リダイレクト、またはログイン保護されたフォルダーへのリンクは失敗します。
4. URL 内のスペースと特殊文字。スペースをエンコードします (eBay は `%20` を要求します)。
5. エンコーディングまたは区切り文字が間違っています。 Excel では、セミコロンまたは非 UTF-8 テキストをエクスポートできます。
6. 識別子 (SKU、バーコード、URL ハンドル) が重複しているか欠落しています。
7. 驚きを上書きします。 Shopify では、空白セルにより既存のデータが消去される可能性があります。

## アップロード前のチェックリスト

- カテゴリとプラットフォームごとに新しいテンプレートをダウンロードします。
- 完全なカタログの前に 5 行でテストします。
- プライベート ブラウザ ウィンドウですべての画像 URL を開きます。画像自体が表示されるはずです。
- タイトル、説明、タグの制限をプラットフォームの現在のガイドラインに照らして確認してください。
- ソース ファイルとプラットフォームのエラー レポートのバックアップを保管してください。

## photoZseo が適合する場所

ファイルの一括アップロードは、ファイル内の画像とテキストと同様にのみ機能します。 photoZseo は、46 のマーケットプレイス用に製品写真を準備し (サイズ変更、圧縮、SEO ファイル名、デバイス上の背景の削除)、iPhone および iPad アプリから CSV、XLSX、または JSON をエクスポートします。 Shopify に製品を送信する以外に、画像をホストしたり、マーケットプレイスにアップロードしたりすることはありません。 [ダウンロードページ](/ja/download) でアプリを入手します。 [Chrome拡張機能](/ja/chrome-extension) は、コンピューターで閲覧する製品ページに対しても同じことを行います。

*photoZseo はどのマーケットプレイスとも提携または承認されていません。マーケットプレイス名は互換性を説明するためにのみ使用されます。*

*注: Amazon Seller Central および Trendyol Akademi ページは検証中に完全に開くことができなかったので、これら 2 つのプラットフォームの詳細は公式ページの検索抜粋から得られます。自分のアカウント内のテンプレートの手順を必ず確認してください。*
