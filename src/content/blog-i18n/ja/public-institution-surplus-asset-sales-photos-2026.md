余剰資産を保存できる方法で撮影するには、すべてのアイテムに同じ固定の写真セットを使用し、資産タグをフレーム内に収め、摩耗や損傷をオープンに表示し、すべてのファイルに資産番号の後に名前を付けます。次に、元のファイルを 1 つのアーカイブに保存し、アイテムごとにスプレッドシートの 1 行を含めます。それがシステム全体です。このガイドの残りの部分では、学校の物置の片付け、病院の設備の撤去、スクラップや古い在庫の売却を行う公共団体や企業向けにこのガイドを実行する方法を示します。

*最終確認日: 2026 年 11 月。このガイドは、写真と記録に関する一般的な推奨事項です。これは法律、税金、調達に関するアドバイスではありません。公共団体、団体、財団による販売は通常、独自の規制や内部規則によって管理されるため、独自の販売規則および関連当局または販売プラットフォームの規則に従ってください。ここでは、法的基準や手順については意図的に述べていません。*

## 機関投資家向け余剰販売に別の写真アプローチが必要な理由

新商品の販売者は魅力的な写真を求めています。中古品を販売する機関には、その逆である、正直で比較可能な、追跡可能な写真が必要です。これらの販売の特徴は 3 つあります。

- 多くの場合、購入者は最初に検査することができません。写真は検査の様子です。オンライン オークションの出品には通常、写真が商品を正確に表現しているとは限らず、書面による説明が優先するという通知が記載されています。そのため、写真と説明は一致する必要があります。
- 後で誰かが販売をレビューする可能性があります。監査人、取締役会、検査官、あるいは失望した入札者は、正確に何がどのような状態で販売されたのかを尋ねるかもしれません。
- 何百ものアイテム、たくさんの写真家。ルールがなければ、従業員ごとに写真の撮り方が異なり、IMG_4821.jpg などのファイル名は 1 か月後には何の意味も持ちません。

## うまくいったシナリオ（仮説）

たとえば、作業場を置き換えている専門学校を考えてみましょう。作業台やボール盤からオフィスチェア、30 台のモニター、混合ケーブルのパレットに至るまで、約 400 個の品目が含まれています。学校は抽選販売を希望しています。職員2名が午後2名と学校の電話を担当します。

システムがなければ、ラベルのない写真が 2,000 枚も残ることになります。 1 つを使用すると、次のことが行われます。

1. 資産番号ラベルがない品目については、資産番号ラベルを印刷するか、既存の在庫タグを使用して、見える場所に貼り付けます。
2. 簡単な撮影スポット (均一な光が当たる壁または床エリア) を設定し、すべてのアイテムを同じ順序で撮影します。
3. ファイルの名前変更と並べ替えは、後でではなくその日に行います。
4. 資産番号をキーとして、アイテムまたはロットごとに 1 行の 1 つのシートを作成します。
5. トリミングされたコピーのみを公開します。オリジナルをそのままアーカイブします。

## 写真リスト：アイテムごとに何を撮影するか

| 写真 | 目的 | に適用されます |
|---|---|---|
| 1. 概要、フロント 3/4 | 購入者に商品を認識してもらう | すべてのアイテム |
| 2. フレーム内のアセットタグ/シリアルプレート | 写真を記録にリンクします | 1つあるすべてのアイテム |
| 3. 背面または側面 | ポート、ラベル、隠れた摩耗を表示 | 設備、家具 |
| 4. スケールの基準 | サイズを表示します（定規またはその横の標準オブジェクト） | サイズが重要なアイテム |
| 5.各欠陥、クローズアップ | 正直な状態：へこみ、錆、ひび割れ、部品欠品 | あらゆる不良品 |
| 6. 動作状態（テストした場合） | 画面がオン、モーターが作動、シートに日付が記載されている | 電子機器、機械 |
| 7. ロット概要 | 混合ロットのすべてのピースをまとめて表示します | ロット、パレット |

背の高い商品でない限り、横向きで撮影してください。日光または室内光を使用し、光沢のある表面ではフラッシュの映り込みを避けてください。

## 状態を正直に表示: シンプルなグレーディングスケール

短いコンディションスケールを選択し、写真セットとリストテキストの両方で使用します。各レベルを一文で定義し、スタッフが同じ方法で採点できるようにします。例えば：

| 学年 | 意味（あなた自身の言葉遣い） | 写真が必要です |
|---|---|---|
| A | 動作しますが、軽い外観上の摩耗のみです | 概要 + タグ |
| B | 動作、目立つ摩耗 | 概要 + タグ + ウェアのクローズアップ |
| C | 故障または不完全な状態で動作する | 概要 + タグ + すべての欠点 |
| D | 動作しない、部品またはスクラップ用 | 概要 + タグ + 失敗する理由 |

上記のスケールは一例にすぎません。自分のルールに合わせて調整してください。重要なのは、グレード、説明、写真が同じストーリーを伝えているということです。購入者は実物を実際の状態で見る必要があるため、ダメージを編集したり、中古品の背景を削除したり補正ツールを使用したりすることは絶対に避けてください。

## 資産番号によるファイルの名前付け

ファイル名は最も安価なコントロールです。識別子を最初に置き、形式を固定し、スペースを避けてください。

| ファイル名の例 | それがあなたに伝えること |
|---|---|
| 2024-0173_概要.jpg | アセット 2024-0173、メイン写真 |
| 2024-0173_tag.jpg | 身元を証明する資産タグ |
| 2024-0173_欠陥-1.jpg | 最初の欠陥のクローズアップ |
| LOT-07_概要.jpg | ロト7、集合写真 |
| LOT-07_アイテム-03.jpg | ロット7内の3枚目 |

これを機能させるためのルール: 在庫番号を登録簿に表示されているとおりに正確に使用し、リストが正しくソートされるように先頭のゼロを保持し、小文字の接尾辞を使用し、番号を再利用しないこと。アイテムに資産番号がない場合は、一時的な資産番号 (TMP-0001 など) を作成し、シートに記録します。

## 項目ごとに 1 つのシート、1 行

写真セットとリストを単一の CSV またはスプレッドシートで同期させます。最小限の列セットは次のようになります。

| カラム | 例 |
|---|---|
| 資産番号 | 2024-0173 |
| 説明 | ピラードリル 230V チャックキー付 |
| 状態_グレード | B |
| 欠陥 | ベースのペイントが剥がれています。ベルトカバー欠品 |
| テスト済み | はい、記載された日付 |
| ロット番号 | LOT-07 |
| 写真ファイル | 2024-0173_概要.jpg; 2024-0173_tag.jpg |
| 撮影者 / 日付 | イニシャル、2026-11-20 |

資産番号はファイル名とシートの両方に含まれているため、リスト、販売記録、アーカイブを数秒でクロスチェックできます。これにより、スプレッドシートを受け入れるプラットフォーム上での一括アップロードも簡単になります。 [CSV および XLSX の一括インポート](/ja/blog/bulk-csv-xlsx-import-46-marketplaces-2026) と同じ考え方が当てはまります。

## 写真内の個人データを保護する

施設内のスペースには、撮影するつもりのなかった個人データが溢れています。何かが公開される前に:

- 背景の顔と人物: トリミングまたはカバーします。
- 車や駐車場のナンバー プレート: 発行されたコピーでカバーします。
- 文書、ファイル、ラベル、ホワイトボードなど、患者、学生、従業員、顧客の名前は、目に見える場所にあることがよくあります。可能な場合は、写真を撮る前に書類を取り除いてください。
- 画面とハードドライブ: 画面をオフにします。独自の IT ポリシーに従って、販売前にストレージ デバイスを消去します。ログイン画面の写真もセキュリティ上の問題です。
- 画像ファイルに埋め込まれた位置データ: 携帯電話が位置データを書き込むかどうかを確認し、位置情報を共有したくない場合は、公開コピーからそのデータを削除します。

データ保護ルールは国によって異なり (EU の GDPR やトルコの KVKK など)、教育機関によっては独自のポリシーがある場合があります。不明な場合は、データ保護担当者に問い合わせてください。未編集のオリジナルは、アクセスが制限された内部アーカイブにのみ保管してください。

## 監査を経ても残るアーカイブを構築する

監査対応の写真アーカイブには特別なソフトウェアは必要ありません。必要なのは規律だけです。

- 販売またはロットごとに 1 つのフォルダーがあり、日付と販売参照で名前が付けられます。
- オリジナルは手付かず。公開可能なコピーは別のサブフォルダーに保存されます。
- 写真の隣に保存されたシートは、セール終了時に PDF または CSV にエクスポートされます。
- 誰が撮影したのか、いつシートに記録されたのか。
- 保存期間はこの記事ではなく、独自の記録ポリシーによって設定されます。
