La plupart des photos de produits sont téléchargées sous le nom `IMG_0421.jpg`. Cela gaspille un signal gratuit que les moteurs de recherche utilisent pour comprendre l’image.

## Ce que dit Google

Le [Meilleures pratiques de référencement d'images](https://developers.google.com/search/docs/appearance/google-images) de Google recommande des noms de fichiers courts mais descriptifs : `my-new-black-kitten.jpg` est meilleur que `IMG00023.JPG`. Google recommande également de traduire les noms de fichiers pour les pages localisées et, pour les sites volumineux, d'automatiser la dénomination.

## Un modèle de dénomination pour les produits

Utilisez cet ordre, en minuscules, avec des traits d'union entre les mots :

`brand-product-key-attribute-view.jpg`

| Mauvais | Bien |
|---|---|
| `IMG_0421.jpg` | `acme-walnut-cutting-board-large-front.jpg` |
| `photo1.png` | `acme-walnut-cutting-board-large-side.jpg` |
| `DSC08812.JPG` | `nova-ceramic-mug-350ml-white-lifestyle.jpg` |

Conseils:

- Soyez bref : 3 à 6 mots significatifs.
- Ajoutez la vue (recto, arrière, côté, détail, étiquette, style de vie) afin que chaque image d'une liste ait un nom unique.
- Ne bourrez pas de mots-clés. Une description claire vaut mieux qu’une liste de synonymes.
- Évitez les caractères spéciaux et les espaces ; Les lettres non latines sont mieux translittérées pour les URL.
- Traduire pour chaque marché, par ex. `kirmizi-deri-cuzdan-on.jpg` pour un magasin turc.

## Le nom du fichier, le texte alternatif et le titre fonctionnent ensemble

Le nom du fichier est l'un des trois signaux texte sur une image de produit. Les deux autres sont [texte alternatif](/fr/blog/product-image-alt-text-examples) et le texte autour de l'image sur la page. Gardez les trois cohérents.
