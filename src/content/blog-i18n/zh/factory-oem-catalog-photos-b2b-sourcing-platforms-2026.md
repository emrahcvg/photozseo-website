OEM 或 ODM 工厂应该为一位读者拍摄其目录：一位买家正在屏幕上比较五个供应商，但无法挑选任何东西。这意味着首先要有一个干净的完整产品图像，然后是特写镜头，以回答买家通过电子邮件提出的问题：它是由什么制成的，它是如何连接的，标签上写着什么，它是如何包装的。照片只是工作的一半。另一半是您在采购平台、询价回复和报价 PDF 中命名、调整和重用它们的一致性。

*最后验证日期：2026 年 11 月。检查来源：HKTDC Sourcing，《摄影技巧》（支持文章）； Global Sources，供应商帮助“图像指南”（仅限搜索列表；当我尝试打开该页面时，该页面本身受到速率限制）。阿里巴巴和 Made-in-China.com 在卖家帐户帮助区域中发布了他们的图片规则，我无法从公共页面确认这些规则，因此这里没有出现这两个的数字。*

## 买家实际上在工厂目录中寻找什么？

采购 OEM 产品的进口商和品牌所有者往往会寻找三件事的证据：产品是否符合他们的规格、工厂是否一致以及工厂是否有人正确回答。照片支持前两个。

假设有一家工厂生产 60 种不锈钢厨房产品。买家想知道金属的规格、手柄是如何固定的、表面处理是拉丝还是抛光、以及纸箱是什么样子。每个产品一张英雄照片都不能回答这个问题。一套六个就可以了。

| 图像槽 | 它显示了什么 | 提问它回答 |
|---|---|---|
| 1. 主要 | 整个产品，纯色背景，居中 | 它是什么？ |
| 2. 角度 | 顶部或侧面，相同的照明 | 形状和深度是多少？ |
| 3. 材质 | 表面或切割边缘的特写 | 什么表面处理和材料？ |
| 4. 施工 | 接头、焊接、缝合、铰链、紧固件 | 制作得如何？ |
| 5. 标签/品牌 | 标志区、吊牌、铭牌 | 我的品牌可以到这里吗？ |
| 6. 包装 | 内包装和出口纸箱 | 如何运送？ |

保持所有 60 种产品的订单相同。买家滚动目录可以了解两种产品的模式，然后阅读速度更快。

## B2B 采购平台对产品图片有何评价？

规则因平台而异，并且会随着时间的推移而进行编辑，因此请将您在博客中阅读的任何数字视为起点，而不是要求。

| 平台 | 官方页面所说的内容（已验证） | 该怎么办 |
|---|---|---|
| 香港贸发局采购 | 摄影技巧：纯白色背景；顶部、底部和侧面的单独照片（最多 15 张照片加一个视频）；项目大约占据框架的 80% 到 90%；照片中没有电子邮件地址或 URL； JPG、JPEG 或 PNG，大于 550 x 550 像素，建议 1,500 x 1,500 像素，72 dpi 以上，5 MB 以下，RGB | 使用这些作为保守的基线并重新检查实时页面 |
| Global Sources | 供应商形象指南历来要求白色背景，但部分透明的产品除外。旧版本列出了小像素尺寸和冲突的分辨率值 | 验证您的供应商帐户中的当前号码 |
| 阿里巴巴 | 规格位于卖家帐户帮助中；无法从公共页面确认 | 阅读您帐户中的上传屏幕和帮助中心 |
| Made-in-China.com | 公共帮助中心未列出图像规格 | 询问您的客户经理或阅读上传屏幕 |

实践课程：从大型母版导出（例如，如果相机允许，最长边为 2,000 像素或更多）并按平台缩小比例。以后升级小文件是行不通的。

## 工厂应该如何拍摄产品？

你不需要工作室。你需要可重复性。

1. 1个固定拍摄角。同一张桌子，同样的背景，同样的光线。一张白色的纸、两个漫射灯和一个三脚架每周都会击败不同的设置。
2. 按批次拍摄，而不是按订单拍摄。在一次拍摄中拍摄一个系列的所有样本，以便颜色和阴影匹配。
3. 添加规模。将一把尺子或一只手放在一个额外的框架中。买家经常会询问您已经测量过的尺寸。
4. 诚实地展示缺陷。如果铸件有分型线，请显示出来。到货时发现它的买家是一个流失的客户；买家看到并批准该订单即为重复订单。
5. 标记模型。如果您在尚不存在的产品上显示买家徽标，请将图像标记为“模型”。
6. 照片包装最后。纸箱标记、条形码和托盘照片可以帮助买方的物流人员。

## 询价如何改变摄影工作？

收到的 RFQ（报价请求）中包含数量、规格，有时还包含目标价格。您的回复通常会在一两天内与其他人竞争。最快的回复会重复使用组织好的照片库。

拥有 60 个 SKU 的工厂的实际假设流程：

| 步 | 行动 | 使用的照片资源 |
|---|---|---|
| 1 | 将询价与 SKU 或近似变体相匹配 | 目录主图+角度图 |
| 2 | 确认定制（颜色、徽标、尺寸） | 变体和模型图像 |
| 3 | 提供样品 | 示例照片集（见下文） |
| 4 | 发送报价 | 每个行项目都带有缩略图的 PDF |
| 5 | 样品发货后跟进 | 包装箱照片和跟踪 |

## 样本照片集中包含哪些内容？

样品就是承诺。离开前拍一张照片：

- 正面、背面和两侧，可见尺子
- 标签或铭牌清晰可见
- 买家在询价中标记的任何细节（铰链、拉链、接缝、螺纹）
- 样品在其包装中，密封，运输标签可见
- 如果产品有机械装置，则为短剪辑

将它们存储在询价或样品编号下。如果买家后来说“样品不同”，那么无论哪种方式，您都已经在证据上标注了日期。

## 报价 PDF 包含哪些内容？

买家希望能够将报价转发给财务和物流同事。典型字段包括带有缩略图的产品线、数量、单价、价格基础（例如带有指定地点的 Incoterms 2020 术语）、付款条件、最小起订量、交货时间、有效期和银行详细信息。 HS 代码可帮助买家估算关税。增值税、出口退税或特定文件是否适用取决于所涉及的国家/地区，因此请与您自己的会计师或报关行确认，而不是复制模板。

## 工厂目录照片的预发布清单

- [ ] 主图以纯色背景展示整个产品
- [ ] 每个 SKU 的槽位顺序相同
- [ ] 图片中不得包含电话号码、电子邮件地址、网址或水印，除非平台允许
- [ ] 文件名说明图像是什么，例如 `ss-teapot-1l-brushed-side.jpg`
- [ ] 一位大主养；从它导出的平台副本
- [ ] 颜色与实物相符（白平衡固定，未过滤）
- [ ] 模型标记
- [ ] 本月实时上传屏幕上重新读取平台限制
