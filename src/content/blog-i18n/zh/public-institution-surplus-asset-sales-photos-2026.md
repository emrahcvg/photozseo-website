要以经得起考验的方式拍摄剩余资产，请为每件物品使用相同的固定照片集，将资产标签放在框架中，公开显示磨损和损坏，并以资产编号命名每个文件。然后将原件保存在一个存档中，每个项目一个电子表格行。这就是整个系统。本指南的其余部分展示了如何为学校清理储藏室、医院报废设备或出售废料和旧库存的公共机构或公司运行它。

*最后验证时间：2026 年 11 月。本指南是照片和记录的一般良好实践。这不是法律、税务或采购建议。公共机构、协会和基金会的销售通常受其自身的法规和内部规则约束，因此请遵循您自己的销售规则以及相关机构或销售平台的规则。我们没有故意在此说明任何法律门槛或程序。*

## 为什么机构剩余销售需要不同的照片方法

一位新产品卖家想要一张迷人的照片。销售二手物品的机构需要相反的东西：诚实、可比且可追踪的照片。三件事使这些销售与众不同。

- 买家往往无法先验货。照片是检查时的照片。在线拍卖清单通常会注明照片可能无法准确反映物品，以书面描述为准，这就是为什么照片和描述必须一致。
- 稍后有人可能会审查销售情况。审计员、董事会、检查员或失望的投标人可能会询问到底出售了什么以及状况如何。
- 数百件物品，许多摄影师。如果没有规则，每个员工拍摄的照片都会不同，一个月后，诸如 IMG_4821.jpg 这样的文件名就毫无意义。

## 一个可行的场景（假设）

以一所职业学校正在更换车间为例：大约有 400 件物品，从工作台、钻床到办公椅、30 台显示器和一堆混合电缆。学校想批量出售。两个工作人员有两个下午和学校的电话。

如果没有系统，他们最终会得到 2,000 张未标记的照片。对于其中一个，他们这样做：

1. 为缺少资产编号的物品打印资产编号标签，或使用现有的库存标签，并将其粘贴在可见的地方。
2. 设置一个简单的拍摄点（光线均匀的墙壁或地板区域）并按相同的顺序拍摄每件物品。
3. 在当天而不是稍后重命名和排序文件。
4. 构建一张表，每个项目或批次一行，以资产编号为键。
5. 仅发布裁剪后的副本；将原件原封不动地存档。

## 照片列表：每件物品要拍摄什么

| 照片 | 目的 | 适用于 |
|---|---|---|
| 1. 概述，前四分之三 | 让买家认出该商品 | 每一项 |
| 2. 框架内的资产标签/序列号牌 | 将照片链接到记录 | 每一项都有一个 |
| 3.背面或侧面 | 显示端口、标签、隐藏磨损 | 设备、家具 |
| 4. 刻度参考 | 显示尺寸（标尺或旁边的标准物体） | 尺寸很重要的物品 |
| 5.每个缺陷，特写 | 真实状况：凹痕、生锈、裂纹、零件缺失 | 每件有缺陷的物品 |
| 6. 工作状态，若测试 | 屏幕打开，电机运转，日期在表中注明 | 电子、机械 |
| 7. 批次概览 | 显示混合批次的所有部件 | 批次、托盘 |

拍摄风景照片，除非物体很高。使用日光甚至室内光，并避免在光滑表面上产生眩光。

## 诚实地显示状况：简单的分级标准

选择一个简短的条件比例并在照片集和列表文本中使用它。用一句话定义每个级别，以便工作人员以相同的方式评分。例如：

| 年级 | 意思（你自己的措辞） | 需要照片 |
|---|---|---|
| A | 有效，仅轻度化妆 | 概述+标签 |
| B | 工作正常，可见磨损 | 概览+吊牌+佩戴特写 |
| C | 工作有错误或不完整 | 概述+标签+每一个故障 |
| D | 不工作，零件或废料 | 概述+标签+失败原因 |

上面的比例只是一个例子；使其适应您自己的规则。关键是等级、描述和照片讲述的是同一个故事。切勿编辑损坏并避免在二手物品上使用背景去除或增强工具，因为买家应该看到真实物体的真实状态。

## 按资产编号命名文件

文件名是最便宜的控件。将标识符放在前面，保持格式固定，并避免空格。

| 示例文件名 | 它告诉你什么 |
|---|---|
| 2024-0173_概述.jpg | 资产 2024-0173，主照片 |
| 2024-0173_tag.jpg | 资产标签，作为身份证明 |
| 2024-0173_缺陷-1.jpg | 第一个缺陷特写 |
| LOT-07_概述.jpg | 拍品7，集体照 |
| LOT-07_item-03.jpg | 7号地块内的第三件 |

保持此功能正常运行的规则：完全按照登记册中显示的库存编号使用，保留前导零以便列表正确排序，使用小写后缀，并且切勿重复使用编号。如果某项没有资产编号，请创建一个临时资产编号（例如 TMP-0001）并将其记录在工作表中。

## 一张纸，每项一行

让照片集和列表与单个 CSV 或电子表格保持同步。最小的列集可能是：

| 柱子 | 例子 |
|---|---|
| 资产编号 | 2024-0173 |
| 描述 | 柱钻，230 V，带卡盘钥匙 |
| 条件等级 | B |
| 缺陷 | 底座上的油漆剥落；皮带盖缺失 |
| 经测试 | 是的，注明日期 |
| 批号 | LOT-07 |
| 照片文件 | 2024-0173_概述.jpg； 2024-0173_tag.jpg |
| 拍摄日期/拍摄日期 | 首字母缩写，2026-11-20 |

由于资产编号同时包含在文件名和表格中，因此可以在几秒钟内交叉检查列表、销售记录和档案。这也使得在任何接受电子表格的平台上批量上传变得简单；同样的想法也适用于 [批量导入 CSV 和 XLSX](/zh/blog/bulk-csv-xlsx-import-46-marketplaces-2026)。

## 保护照片中的个人数据

机构空间充满了您无意拍摄的个人数据。在发布任何内容之前：

- 背景中的面孔和人物：裁剪或覆盖它们。
- 车辆和停车场的车牌：将其覆盖在公布的副本中。
- 文档、文件、标签和白板：患者、学生、员工或客户的姓名通常位于显眼位置。尽可能在拍照前取出文件。
- 屏幕和硬盘驱动器：关闭屏幕。根据您自己的 IT 政策，在销售前擦除存储设备；登录屏幕的照片也是一个安全问题。
- 图像文件中嵌入的位置数据：检查您的手机是否写入了该数据，如果您不希望共享该位置，请将其从已发布的副本中删除。

数据保护规则因国家/地区而异（例如欧盟的 GDPR 或土耳其的 KVKK），并且您的机构可能有自己的政策。如果您不确定，请询问您的数据保护官员。仅将未经编辑的原件保留在您的内部档案中，并限制访问。

## 建立一个能够通过审核的档案

可供审计的照片档案不需要特殊的软件，只需要纪律。

- 每个销售或批次一个文件夹，以日期和销售参考命名。
- 原件未动过；可发布的副本位于单独的子文件夹中。
- 该表保存在照片旁边，在销售结束时导出为 PDF 或 CSV。
- 谁拍摄的以及何时记录在表中。
- 保留期由您自己的记录政策设置，而不是由本文设置。
