供应商图像包是一组可下载的产品照片，按 SKU 组织，其中包含一个数据文件，说明哪张照片属于哪个产品，以及关于经销商如何使用它们的简短说明。零售商可以将您的包装直接装入商店或市场，更快地列出您的产品，减少错误，并且更有可能重新订购。本指南介绍了实用的包结构、命名规则、尺寸层、使用说明以及将其组合在一起的 CSV。

*最后验证时间：2026 年 11 月。检查来源：美国版权局（版权常见问题解答）、Shopify 帮助中心（使用 CSV 文件导入和导出产品）、ICC（国际贸易术语解释通则 2020 规则页面）。*

## 为什么零售商要求提供图像包

例如，想象一家供应商拥有 300 个 SKU 的厨具。二十家零售商每季都会发送相同的电子邮件：“你能发送新颜色的照片吗？” “24厘米盘是哪个锉刀？” “图中的盖子有吗？”供应商以共享驱动器链接、IMG_4821.jpg 等文件名以及与文件夹顺序不同的价目表进行答复。

然后，零售商花费数小时手工将照片与行进行匹配。几乎肯定会出现错误：错误的商品颜色、错误的套装照片以及 SKU 不包含的配件，以及在两个产品下上传的同一张照片。包消除了这项工作，并将其转移给最了解产品的一方，即供应商。

## 包装中包含什么

| 物品 | 它是什么 | 为什么零售商需要它 |
|---|---|---|
| 照片由 SKU 提供 | 每个 SKU 一个文件夹，或每个文件名中包含 SKU 的一个平面文件夹 | 快速导入，无需猜测 |
| 产品数据 CSV | 每个 SKU 一行：名称、条形码、颜色、尺寸和图像文件名 | 将照片映射到产品和价目表 |
| 使用权说明 | 一页：经销商可以做什么和不可以做什么 | 删除权限问题 |
| 自述文件 | 命名规则、尺寸等级、包装日期 | 让新员工单独使用该包 |
| 变更日志 | 自上一包以来添加或替换的内容 | 零售商仅更新发生变化的内容 |

保持第一个版本较小。一个涵盖最佳 50 个 SKU 且准确的包比半过时的完整档案更有用。

## 零售商可以排序和搜索的命名规则

对每个文件使用一种模式并将其写入自述文件中。一个简单易读的形式是 SKU，然后是视图代码，然后是可选的颜色代码：

- SKU-12345_front.jpg
- SKU-12345_side.jpg
- SKU-12345_back-red.jpg
- SKU-12345_detail-handle.jpg

值得保留的规则：仅限小写字母、数字、连字符和下划线；没有空格或重音字符，因为某些上传系统和操作系统处理它们很糟糕；名称中没有“最终”、“新”或“副本”。由于 SKU 引导名称，因此文件彼此相邻排序，并且可以通过简单的查找与价目表进行匹配。

对于搜索引擎，描述性文件名会有所帮助，但供应商包是源文件。许多零售商在发布时会重命名为自己的关键字名。我们的 [如何为 SEO 命名产品照片](/zh/blog/how-to-name-product-photos-for-seo) 指南展示了第二步的样子，因此您知道为什么基于 SKU 的干净原创是最好的起点。

## 尺寸等级：主尺寸、网页尺寸和缩略图尺寸

市场会改变其图像规则，因此不要尝试为每个平台预先安装一个文件。相反，给每张照片划分几层，并告诉零售商它们来自哪里。下面的数字是建议的起始设置，而不是平台要求。

| 等级 | 建议使用 | 建议规格（供应商选择） |
|---|---|---|
| 掌握 | 存档和重新裁剪 | 原始或高分辨率 JPEG 或 PNG，无重度压缩 |
| 网络 | 商店和大多数市场 | 方形画布，长边约 2000 像素，JPEG |
| 缩略图 | 列表、报价、目录 | 长边大约 600 px |

如果您知道您的零售商在特定平台上销售，请添加适合该平台大小的文件夹。首先检查每个平台当前的卖家指南。有关多个市场期望的参考，请参阅 [](/zh/marketplace-image-sizes)。像素值会发生变化，因此页面会链接到它们的来源，而不是承诺它们是永久性的。

## 照片一致性比分辨率更重要

即使每个文件都很清晰，在不同日期、不同光线下拍摄的包装在零售商的页面上看起来也很糟糕。在拍摄之前，先确定三件事：背景（白色或浅灰色，整个范围相同）、相机角度设置（例如正面、侧面、背面、细节、比例）和取景，以便产品填充画面的相似份额。使用三脚架或固定距离。一组固定的角度还可以防止零售商要求您“再提供一张照片”。

对于变体，在相同位置拍摄每种颜色并用颜色代码命名。不要拍摄一种颜色并告诉零售商在编辑器中更改它。

## 使用权说明

照片一经创作就受到版权保护。美国版权局常见问题解答称，作品一旦以有形形式创作和固定，即受到保护，并且注册是自愿的。这意味着零售商不能安全地假设您的文件可供他们免费使用，好的零售商会询问。一个简短的说明提前回答了这个问题。

该便条通常涵盖哪些内容，用您自己的话书写并由您所在国家/地区的律师检查：

1. 谁拥有这些照片（您或拥有您许可的摄影师）。
2. 谁可以使用它们（您的授权经销商，只要他们库存您的产品）。
3. 哪里（他们自己的商店、市场、社交帖子、印刷目录）。
4. 他们可能会改变什么（调整大小、裁剪和重命名，但不添加误导性文本或其他品牌的徽标）。
5. 关系结束时会发生什么（在合理期限内删除图像）。

这是一种沟通工具，而不是法律建议。如果您的照片包含摄影师的作品、模特或其他人的品牌，请先确认您自己的权利。

## 连接一切的 CSV

CSV 是零售商最看重的部分。每个 SKU 一行，列按固定顺序排列。实际最低限度：

| 柱子 | 例子 |
|---|---|
| 存货单元 | SKU-12345 |
| 条形码 | 产品的 EAN 或 UPC（如果有） |
| 产品名称 | 您想要使用的名称 |
| 颜色、尺寸 | 变体字段 |
| 图像主 | SKU-12345_front.jpg |
| image_2 到 image_6 | 其他视图文件 |
| 包版本 | 2026-11 |

如果您的零售商使用 Shopify，这自然会映射到其产品 CSV。根据 Shopify 帮助中心，产品 CSV 包含产品图像 URL、图像位置、图像替代文本和单独的变体图像 URL 列，Shopify 在导入过程中从公共 URL 下载图像并将其重新上传到商店。替代文本字段最多可容纳 512 个字符，Shopify 建议将其保持在 125 个或更少。将您的网络层上传到公共地址，将 URL 添加到 CSV，零售商可以一次性导入整个系列。在向合作伙伴承诺任何专栏名称之前，请先阅读 Shopify 的当前页面。 [Shopify CSV 与 API](/zh/blog/shopify-csv-vs-api-2026) 中导入方法的比较可帮助您决定为它们记录哪种路径。

如果您还提供批发条款，请在单独的贸易数据选项卡中包含 HS 代码和原产国。您的零售商或报关行将其用于跨境订单，您应与合格的专业人员确认正确的分类。

## 工作流程示例

上述 300 个 SKU 供应商的每周例程说明如下：

1. 在固定设置上拍摄新的或更改的产品。
2. 使用 SKU 规则重命名原始文件。
3. 将三层导出到包文件夹中。
4. 更新 CSV 行和包版本。
5. 测试：打开 CSV，随机抽取 5 行并检查文件夹中是否存在每个文件名。
6. 将包发布到一个共享链接，并向零售商发送一封两行更改日志。

第五步是大多数供应商都会跳过的一步，它几乎可以捕获所有错误。

## 寄送包裹前的检查清单

- [ ] 价目表中的每个 SKU 包装中至少有一张照片。
- [ ] 每个文件名都遵循规则，不能有空格。
- [ ] CSV 中的每个文件名都存在，反之亦然。
- [ ] 背景和角度设置在整个范围内保持一致。
- [ ] 没有可见的第三方徽标、水印或未经许可的型号。
- [ ] 使用权利说明和版本日期位于包中。
- [ ] 为需要丢失照片的零售商提供了单线联系方式。
