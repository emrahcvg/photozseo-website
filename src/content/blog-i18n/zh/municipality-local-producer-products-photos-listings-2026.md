为了在网上列出当地生产商的产品，市政当局在需要相机之前需要三件事：共享的视觉标准、每个生产商填写的产品信息表以及文件命名规则。有了这些，一个拥有十几罐蜜饯的妇女合作社和一个拥有两种奶酪的家庭乳品店就可以位于同一个目录中，看起来就像是一个连贯的区域产品的一部分。没有它们，您将获得 40 种不同的背景、40 种命名习惯和无人能比的列表页面。

*最后验证时间：2026 年 11 月。这是实用的照片和列表指南。它不是法律建议，也不描述任何市政当局的销售、招标或采购规则；遵循您自己的立法。市场图像规则发生变化，因此请检查您列出的每个平台的当前指南。*

## 多制作者目录中的实际问题是什么？

下面的场景是假设的，以展示作品的形状。一个区市政府与 35 个生产商一起开展本地产品计划：一个妇女合作社（果酱、泡菜、干香草）、两个蜂蜜饲养员、一个橄榄油压榨机、一个手工艺小组（编织袋、毛毡）和一些小面包师。他们想要一个在线存在，并且对于那些愿意的人来说，在区域或国家市场上列出。

典型的故障是可以预见的：

- 每个制作人都会发送不同背景和光线的手机照片
- 产品名称有四种写法（“Thyme”、“dried thyme 50g”、“Kekik”、“KEKIK 50 GR”）
- 同一产品在不同页面上显示的权重不同
- 照片被命名为`IMG_2231.jpg`，但没有人知道它们是谁的

## 第 1 步：编写一页视觉标准

将其保留在合作社成员无需培训即可操作的一页上。

| 规则 | 标准（示例，根据自己的情况进行调整） |
|---|---|
| 主图 | 整个产品，纯浅色背景，居中，框架中没有其他内容 |
| 第二张和第三张图片 | 带有成分、纹理或工艺细节特写的背面标签 |
| 生活方式形象 | 一、可选，设置简单，所有制作者风格一致 |
| 光 | 窗户日光或两盏柔光灯，无闪光灯 |
| 方向 | 所有主图像的长宽比相同（决定一次） |
| 道具 | 只有当他们解释用途（蜂蜜勺）时，才不会使用其他品牌 |
| 标志和文字 | 无添加水印；产品标签显示了它所显示的内容 |
| 修饰 | 仅修复亮度和裁剪；不改变产品的颜色或形状 |

通过查看您计划使用的最严格的市场来选择宽高比，然后保留更大的母版。检查该平台当前图像页面的数字，而不是依赖文章中的数字。

## 第 2 步：拍摄前收集产品信息

照片和文字分开制作时会出现问题。使用共享工作表（电子表格即可）。

| 柱子 | 为什么这很重要 |
|---|---|
| 生产者代码 | 短稳定ID；成为文件名前缀 |
| 产品名称（本地语言和另一种语言（如果需要） | 照片标签、表格和清单上的措辞相同 |
| 净重或体积 | 必须与照片中的包装相符 |
| 成分/材质 | 上市所需；还要检查标签是否匹配 |
| 变体 | 味道、大小、颜色 |
| 产地/村庄 | 支持地区故事 |
| 生产者持有的认证或注册 | 只列出生产者可以记录的内容 |
| 人们的照片同意书 | 是/否，对于任何制作人或工作室图像 |

不要在列表中提出生产者无法证明的声明。如果产品具有注册地理标志或有机状态，则由生产商自己的文件决定，而不是目录。

## 第 3 步：举办共享照片日

对于此类节目，每个地区设立一个“摄影日”通常比要求每个制片人单独拍照更有效率。

1. 在靠近窗户的地方摆一张桌子，背景简单，并配有三脚架。
2. 打印照片列表：正面、背面标签、一张详细信息、一张正在使用的照片（如果需要）。
3. 在每个批次的第一帧中放置编号卡（生产者代码），以便批次易于排序。
4. 一起拍摄每个生产商的产品。保持相同的相机距离。
5. 最后，在制片人离开之前在笔记本电脑或平板电脑上进行快速查看，并在现场重新拍摄。

对于无法运输的物品，例如大型工艺品或新鲜商品，经过培训的志愿者或工作人员可以使用相同的工具箱进行访问。

## 第 4 步：命名并组织文件

命名规则可以在数小时后保存。

| 图案部分 | 例子 |
|---|---|
| 生产者代码 | `p014` |
| 产品 | `olive-oil` |
| 尺寸/型号 | `500ml` |
| 看法 | `front`、`label`、`detail` |
| 姓名 | `p014-olive-oil-500ml-front.jpg` |

使用小写字母、连字符、无空格且无特殊字符。描述性的文件名对于搜索引擎在您自己的网站上也有一个小小的帮助。

## 第 5 步：建立生产者档案，而不仅仅是产品卡

区域产品的买家经常购买这个故事。保持产品图片统一，并将身份信息放入个人资料卡中：

- 生产者或合作社名称和地点
- 一个两句话或三句话的短故事
- 经同意的肖像或研讨会图像
- 制作人选择的链接或联系方式

拍摄人物照片时务必征求同意，并与每位制作人共同决定公开哪些联系方式。

## 预发布目录清单

- [ ] 与所有制作者共享的一页视觉标准
- [ ] 每个产品在情况说明书中都有一行
- [ ] 包装、片材和清单之间的重量、名称和型号相匹配
- [ ] 主图占比、背景及取景
- [ ] 文件名遵循规则；没有`IMG_`剩菜
- [ ] 同意记录任何人物图像
- [ ] 文本中没有无法证明的声明（有机、受保护的原产地、健康）
- [ ] 直播平台页面重读平台形象规则
- [ ] 法律部门确认市政府如何参与
