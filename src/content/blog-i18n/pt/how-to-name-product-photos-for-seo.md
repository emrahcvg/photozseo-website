A maioria das fotos dos produtos são carregadas como `IMG_0421.jpg`. Isso desperdiça um sinal gratuito que os motores de busca usam para entender a imagem.

## O que Google diz

O [práticas recomendadas de SEO de imagem](https://developers.google.com/search/docs/appearance/google-images) do Google recomenda nomes de arquivo curtos, mas descritivos: `my-new-black-kitten.jpg` é melhor que `IMG00023.JPG`. Google também recomenda traduzir nomes de arquivos para páginas localizadas e, para sites grandes, automatizar a nomenclatura.

## Um padrão de nomenclatura para produtos

Use esta ordem, em letras minúsculas, com hífens entre as palavras:

`brand-product-key-attribute-view.jpg`

| Ruim | Bom |
|---|---|
| `IMG_0421.jpg` | `acme-walnut-cutting-board-large-front.jpg` |
| `photo1.png` | `acme-walnut-cutting-board-large-side.jpg` |
| `DSC08812.JPG` | `nova-ceramic-mug-350ml-white-lifestyle.jpg` |

Pontas:

- Seja breve – 3 a 6 palavras significativas.
- Adicione a visualização (frente, verso, lateral, detalhe, rótulo, estilo de vida) para que cada imagem em uma listagem tenha um nome exclusivo.
- Não encha palavras-chave. Uma descrição clara supera uma lista de sinônimos.
- Evite caracteres especiais e espaços; letras não latinas são melhor transliteradas para URLs.
- Traduzir para cada mercado, por ex. `kirmizi-deri-cuzdan-on.jpg` para uma loja turca.

## Nome do arquivo, texto alternativo e título funcionam juntos

O nome do arquivo é um dos três sinais de texto na imagem de um produto. Os outros dois são [texto alternativo](/pt/blog/product-image-alt-text-examples) e o texto ao redor da imagem na página. Mantenha todos os três consistentes.
