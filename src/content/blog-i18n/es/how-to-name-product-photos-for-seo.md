La mayoría de las fotos de productos se cargan como `IMG_0421.jpg`. Eso desperdicia una señal gratuita que los motores de búsqueda utilizan para comprender la imagen.

## Lo que dice Google

[Mejores prácticas de SEO de imágenes](https://developers.google.com/search/docs/appearance/google-images) de Google recomienda nombres de archivo cortos pero descriptivos: `my-new-black-kitten.jpg` es mejor que `IMG00023.JPG`. Google también recomienda traducir nombres de archivos para páginas localizadas y, para sitios grandes, automatizar la nomenclatura.

## Un patrón de nomenclatura para productos.

Utilice este orden, en minúsculas, con guiones entre palabras:

`brand-product-key-attribute-view.jpg`

| Malo | Bien |
|---|---|
| `IMG_0421.jpg` | `acme-walnut-cutting-board-large-front.jpg` |
| `photo1.png` | `acme-walnut-cutting-board-large-side.jpg` |
| `DSC08812.JPG` | `nova-ceramic-mug-350ml-white-lifestyle.jpg` |

Consejos:

- Sea breve: de 3 a 6 palabras significativas.
- Agregue la vista (anverso, reverso, lateral, detalle, etiqueta, estilo de vida) para que cada imagen de un listado tenga un nombre único.
- No rellenes palabras clave. Una descripción clara supera a una lista de sinónimos.
- Evite caracteres y espacios especiales; Las letras no latinas se transcriben mejor para las URL.
- Traducir para cada mercado, p.e. `kirmizi-deri-cuzdan-on.jpg` para una tienda turca.

## El nombre del archivo, el texto alternativo y el título funcionan juntos

El nombre del archivo es una de las tres señales de texto en la imagen de un producto. Los otros dos son [texto alternativo](/es/blog/product-image-alt-text-examples) y el texto alrededor de la imagen en la página. Mantenga los tres consistentes.
