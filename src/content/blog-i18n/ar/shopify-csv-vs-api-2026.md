## المساران إلى Shopify

| طريق | ما هو عليه | مصادقة | سرعة | حد المعدل |
|------|-----------|------|-------|------------|
| استيراد CSV | تحميل الملف من خلال مشرف Shopify → المنتجات → استيراد | لا يوجد (مسؤول مسجل الدخول) | ~500 منتج / 5 دقائق | لا شيء - طوابير Shopify |
| REST المشرف API | HTTP POST لكل منتج أو لكل مورد | رمز الوصول عبر التطبيق الخاص/المخصص | ~ 2 منتج / ثانية | 2 مكالمات/ثانية قياسية، 4 بلس |
| واجهة برمجة تطبيقات مسؤول GraphQL | نقطة نهاية واحدة، طفرات جماعية | رمز الوصول | ~5-10 منتجات/الثانية مع العمليات المجمعة | 50 نقطة/ثانية قياسية، 100 زائد |
| واجهة برمجة التطبيقات للعمليات المجمعة | مجموعة Async GraphQL للوظائف الضخمة | رمز الوصول + الاقتراع | غير متزامن، ساعات للإكمال | تعتبر عملية واحدة |

العنوان الرئيسي: ملف CSV أسرع مما يعتقده الناس، وواجهة برمجة التطبيقات (API) أبطأ مما يعتقده الناس، بمجرد بدء حدود المعدل.

## عندما يفوز CSV

- لديك أقل من 1000 منتج. يتعامل ملف CSV مع حجم الدفعة هذا بشكل نظيف.
- يمكنك تشغيل عمليات إطلاق دورية، وليس مزامنة مستمرة للمخزون. تحديثات الكتالوج ربع السنوية تكون على شكل ملف CSV.
- تريد مسار التدقيق دون كتابة التعليمات البرمجية. كل تحميل بتنسيق CSV هو ملف يمكنك الاحتفاظ به في Dropbox/iCloud/Google Drive.
- لا تريد إدارة الرموز المميزة لواجهة برمجة التطبيقات. لا يوجد تطبيق لتثبيته، ولا يوجد رمز مميز للتدوير.
- تريد معاينة التغييرات قبل نشرها. يعرض استيراد ملف CSV الخاص بـ Shopify المنتجات المتأثرة قبل تطبيق التغيير إذا قمت بإلغاء تحديد "نشر المنتجات إلى جميع قنوات المبيعات".
- أنت تعمل عبر متاجر متعددة. يعمل نفس ملف CSV مع أي متجر Shopify. يحتاج عميل API نفسه إلى رمز مميز لكل متجر.

- يمكنك توصيل نقطة بيع مخصصة أو 3PL أو ERP الذي يجب أن ينقل البيانات ذهابًا وإيابًا.
- لديك موارد هندسية للحفاظ على التكامل.
- أنت تعمل في مجال B2B مع تغيرات متكررة في الأسعار تتطلب انتشارًا في أقل من دقيقة.

## صورة SEO داخل ملف CSV

العمودان اللذان يحددان ما إذا كان ترتيب صورك هما Image Src وImage Alt Text.

- يجب أن يكون Image Src عنوان URL عامًا. يجب أن تكون الصورة قابلة للوصول عندما يستوعب Shopify ملف CSV - إذا كان الملف خلف CDN خاص أو مجموعة محمية برمز مميز، فستفشل عملية الاستيراد بصمت.
- نص الصورة البديل هو حقل البحث عن الصور Google، وقراءة الاستشهادات Pinterest ونظرة عامة على الذكاء الاصطناعي. اجعلها أقل من 100 حرف. ابدأ بالمنتج وليس بالعلامة التجارية.

فشل شائع لدى البائع المستقل: تحميل 200 منتج عبر ملف CSV مع ملء عمود Image Src ولكن عمود Image Alt Text فارغ. يقوم Shopify باستيراد الصور بسعادة. يفقد المتجر سطح SEO للصورة بالكامل.
