공급업체 이미지 팩은 SKU별로 구성된 다운로드 가능한 제품 사진 세트로, 어떤 사진이 어떤 제품에 속하는지 알려주는 데이터 파일과 리셀러가 이를 어떻게 사용할 수 있는지에 대한 간단한 메모가 포함되어 있습니다. 상점이나 마켓플레이스에 직접 팩을 넣을 수 있는 소매업체는 제품 목록을 더 빠르게 작성하고 실수를 줄이며 재주문 가능성이 높습니다. 이 가이드는 실용적인 팩 구조, 명명 규칙, 크기 계층, 사용 참고 사항 및 이를 하나로 묶는 CSV를 안내합니다.

*최종 확인 날짜: 2026년 11월. 확인 출처: 미국 저작권 사무소(저작권 FAQ), Shopify 도움말 센터(CSV 파일을 사용하여 제품 가져오기 및 내보내기), ICC(인코텀즈 2020 규칙 페이지).*

## 소매업체에서 이미지 팩을 요구하는 이유

예를 들어 300개 SKU의 주방용품을 보유한 공급업체를 상상해 보세요. 20개의 소매업체는 매 시즌마다 동일한 이메일을 보냅니다. "새로운 색상의 사진을 보내주실 수 있나요?" "24cm 팬은 어떤 파일인가요?" "사진 속 뚜껑도 포함되어 있나요?" 공급업체는 공유 드라이브 링크, IMG_4821.jpg와 같은 파일 이름, 폴더와 다른 순서의 가격 목록으로 응답합니다.

그런 다음 소매점에서는 사진을 직접 행과 일치시키는 데 몇 시간을 소비합니다. 실수는 거의 보장됩니다. 잘못된 목록의 잘못된 색상, SKU에 포함되지 않은 액세서리와 함께 촬영된 세트, 두 제품 아래에 동일한 사진이 업로드되었습니다. 팩은 해당 작업을 제거하고 제품을 가장 잘 아는 당사자인 공급업체로 옮깁니다.

## 팩에는 무엇이 들어있나요?

| 목 | 그것은 무엇입니까 | 소매업체에 필요한 이유 |
|---|---|---|
| SKU의 사진 | SKU당 하나의 폴더 또는 모든 파일 이름에 SKU가 포함된 하나의 플랫 폴더 | 빠른 가져오기 및 추측 없음 |
| 제품 데이터 CSV | SKU당 한 행: 이름, 바코드, 색상, 크기 및 이미지 파일 이름 | 사진을 제품 및 가격표에 매핑합니다. |
| 사용 권한 참고 | 한 페이지: 리셀러가 수행할 수 있는 작업과 수행할 수 없는 작업 | 권한 질문을 제거합니다. |
| 읽어보기 | 명명 규칙, 크기 등급, 포장 날짜 | 신입사원이 단독으로 팩을 사용할 수 있도록 함 |
| 변경 로그 | 지난 팩 이후 추가되거나 교체된 내용 | 소매업체는 변경된 사항만 업데이트합니다. |

첫 번째 버전을 작게 유지하세요. 최고의 50개 SKU를 포함하고 정확한 팩은 절반만 오래된 완전한 아카이브보다 더 유용합니다.

## 명명 규칙 소매업체는 정렬 및 검색이 가능합니다.

모든 파일에 하나의 패턴을 사용하고 Readme에 기록하세요. 간단하고 읽기 쉬운 형식은 SKU, 보기 코드, 선택적 색상 코드입니다.

- SKU-12345_앞면.jpg
- SKU-12345_side.jpg
- SKU-12345_back-red.jpg
- SKU-12345_detail-handle.jpg

지켜야 할 규칙: 소문자, 숫자, 하이픈, 밑줄만 사용 가능; 일부 업로드 시스템과 운영 체제에서는 공백이나 악센트 부호가 있는 문자를 잘못 처리하므로 사용하지 마세요. 이름에 "최종", "새" 또는 "복사본"이 없습니다. SKU가 이름을 주도하기 때문에 파일은 나란히 정렬되며 간단한 조회를 통해 가격표와 일치시킬 수 있습니다.

검색 엔진의 경우 설명이 포함된 파일 이름이 도움이 되지만 공급업체 팩은 소스 파일입니다. 많은 소매업체는 출판할 때 자신의 키워드 이름으로 이름을 바꿉니다. [SEO를 위한 제품 사진 이름 지정 방법](/ko/blog/how-to-name-product-photos-for-seo)에 대한 가이드는 두 번째 단계가 어떤 모습인지 보여주므로 깨끗한 SKU 기반 원본이 최고의 출발점이 되는 이유를 알 수 있습니다.

## 크기 계층: 마스터, 웹 및 썸네일

마켓플레이스는 이미지 규칙을 변경하므로 모든 플랫폼에 하나의 파일을 미리 맞추려고 하지 마십시오. 대신 각 사진에 몇 가지 계층을 부여하고 소매점에 해당 사진의 출처를 알려주십시오. 아래 숫자는 플랫폼 요구 사항이 아닌 권장 시작 세트입니다.

| 층 | 권장 사용 | 권장 사양(공급업체 선택) |
|---|---|---|
| 주인 | 보관 및 다시 자르기 | 원본 또는 고해상도 JPEG 또는 PNG, 심한 압축 없음 |
| 편물 | 상점 및 대부분의 마켓플레이스 | 정사각형 캔버스, 긴 가장자리 약 2000px, JPEG |
| 썸네일 | 목록, 견적, 카탈로그 | 긴 가장자리 약 600px |

소매업체가 특정 플랫폼에서 판매한다는 것을 알고 있는 경우 해당 플랫폼에 맞는 폴더를 추가하세요. 각 플랫폼의 현재 판매자 가이드라인을 먼저 확인하세요. 여러 시장에서 기대하는 사항에 대한 참조는 [마켓플레이스 이미지 크기](/ko/marketplace-image-sizes)를 참조하세요. 픽셀 값이 변경되므로 페이지는 영구적이라고 약속하는 대신 해당 값의 출처로 연결됩니다.

## 사진의 일관성은 해상도보다 더 중요합니다

다른 날에 다른 빛으로 촬영한 팩은 모든 파일이 선명하더라도 소매점 페이지에서는 불량해 보입니다. 사진을 찍기 전에 배경(흰색 또는 밝은 회색, 전체 범위에 동일), 카메라 각도 설정(예: 전면, 측면, 후면, 디테일, 스케일) 및 프레임의 세 가지 사항을 수정하여 제품이 프레임에서 비슷한 부분을 차지하도록 합니다. 삼각대를 사용하거나 고정된 거리를 사용하세요. 또한 고정된 각도 세트로 인해 소매점에서는 "사진 한 장 더"를 요구하지 않습니다.

변형의 경우 모든 색상을 동일한 위치에서 촬영하고 색상 코드로 이름을 지정하세요. 한 가지 색상을 사진으로 촬영한 후 소매업체에 편집기에서 색상을 변경하라고 지시하지 마세요.

## 사용 권한 참고 사항

사진은 제작된 순간부터 저작권으로 보호됩니다. 미국 저작권청 FAQ에서는 저작물이 유형의 형태로 생성되고 고정되면 보호를 받으며 등록은 자발적이라고 말합니다. 이는 소매업체가 귀하의 파일을 무료로 사용할 수 있다고 안전하게 가정할 수 없으며 좋은 소매업체가 물어볼 것임을 의미합니다. 짧은 메모가 미리 답변해 드립니다.

일반적으로 메모에서 다루는 내용은 귀하가 직접 작성하고 해당 국가의 변호사가 확인합니다.

1. 사진의 소유자는 누구입니까(귀하 또는 귀하에게 라이센스가 있는 사진작가).
2. 이를 사용할 수 있는 사람(귀하의 제품을 보유하고 있는 경우 귀하의 공인 리셀러).
3. 장소(자체 상점, 마켓플레이스, 소셜 게시물, 인쇄된 카탈로그).
4. 변경할 수 있는 사항(크기 조정, 자르기 및 이름 바꾸기, 오해의 소지가 있는 텍스트나 다른 브랜드의 로고를 추가하지 않음)
5. 관계가 종료되면 어떻게 되나요? (합리적인 기간 내에 이미지를 삭제하세요.)

이는 법적 조언이 아닌 의사소통 도구입니다. 귀하의 사진에 사진가의 작품, 모델 또는 타인의 브랜드가 포함되어 있는 경우 먼저 귀하의 권리를 확인하십시오.

## 모든 것을 연결하는 CSV

CSV는 소매업체가 가장 중요하게 생각하는 부품입니다. SKU당 하나의 행(고정된 순서의 열 포함) 실제 최소값:

| 열 | 예 |
|---|---|
| sku | SKU-12345 |
| 바코드 | 제품의 EAN 또는 UPC(있는 경우) |
| 제품_이름 | 사용하고 싶은 이름 |
| 색상, 사이즈 | 변형 필드 |
| 이미지메인 | SKU-12345_앞면.jpg |
| image_2 ~ image_6 | 다른 보기 파일 |
| 팩_버전 | 2026-11 |

소매업체가 Shopify를 사용하는 경우 이는 제품 CSV에 자연스럽게 매핑됩니다. Shopify 도움말 센터에 따르면 제품 CSV에는 제품 이미지 URL, 이미지 위치, 이미지 대체 텍스트 및 별도의 변형 이미지 URL에 대한 열이 있으며 Shopify는 가져오는 동안 공개 URL에서 이미지를 다운로드하고 스토어에 다시 업로드합니다. 대체 텍스트 필드는 최대 512자를 포함할 수 있으며 Shopify에서는 125자 이하로 유지할 것을 권장합니다. 웹 계층을 공개 주소에 업로드하고 URL을 CSV에 추가하면 소매업체가 한 번에 전체 범위를 가져올 수 있습니다. 파트너에게 컬럼 이름을 약속하기 전에 Shopify의 현재 페이지를 읽어보십시오. [Shopify CSV와 API](/ko/blog/shopify-csv-vs-api-2026)의 가져오기 방법 비교는 문서화할 경로를 결정하는 데 도움이 됩니다.

도매 조건도 제공하는 경우 별도의 거래 데이터 탭에 HS 코드와 원산지를 포함하세요. 귀하의 소매업체나 통관업자는 국경 간 주문에 이를 사용하므로 귀하는 자격을 갖춘 전문가에게 올바른 분류를 확인해야 합니다.

## 작업 예시 워크플로

위의 300-SKU 공급업체에 대한 예시적인 주간 루틴은 다음과 같습니다.

1. 고정된 설정에서 새 제품이나 변경된 제품을 촬영합니다.
2. SKU 규칙을 사용하여 원본 이름을 바꿉니다.
3. 세 계층을 팩 폴더로 내보냅니다.
4. CSV 행과 팩 버전을 업데이트합니다.
5. 테스트: CSV를 열고 임의의 5개 행을 선택하여 각 파일 이름이 폴더에 있는지 확인합니다.
6. 하나의 공유 링크에 팩을 게시하고 두 줄로 구성된 변경 로그를 소매업체에 이메일로 보냅니다.

5단계는 대부분의 공급업체가 건너뛰는 단계로 거의 모든 오류를 잡아냅니다.

## 택배 보내기 전 체크리스트
