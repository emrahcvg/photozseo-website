Amazon는 대부분의 판매자가 목록을 보기 전에 목록을 거부합니다. 범인은 거의 항상 사진입니다. 너무 무거운 파일, 완전히 흰색이 아닌 배경 또는 플랫폼이 조용히 거부하는 화면 비율입니다.

다음은 Amazon의 판매자 문서에서 가져온 2026년 사양 치트 시트이며 실제 목록과 비교하여 테스트되었습니다.

## 메인 이미지 규칙

- 크기: 최소 1000×1000, 권장 2000×2000. 가장 긴 면이 1000 미만인 경우 Amazon는 확대/축소를 활성화하지 않으며 알고리즘은 확대/축소가 없는 목록을 낮은 품질로 처리합니다.
- 화면 비율: 기본 이미지의 경우 정사각형(1:1)입니다. 보조 이미지는 4:5 또는 16:9일 수 있습니다.
- 배경: 순백색, 육각형 `#FFFFFF`. "백색에 가까운" 사진 스튜디오는 판매자가 예상하는 것보다 더 자주 자동 확인에 실패합니다.
- 형식: JPEG(`.jpg`)가 가장 안전한 선택입니다. TIFF, PNG 및 GIF가 허용되지만 Amazon의 CDN에서는 JPEG가 더 잘 압축되고 더 빠르게 처리됩니다.
- 색공간: sRGB. Adobe RGB 또는 ProPhoto에 저장된 이미지는 Amazon를 다시 인코딩한 후 흐릿하게 보입니다.
- 파일 크기: 이미지당 10MB 미만. 압축 후 200~600KB를 목표로 하세요. 파일이 크면 제품 페이지 로드 속도가 느려지고 페이지 속도가 변환에 영향을 미칩니다.

## 목록이 표시되지 않는 이유

1. 제품 이미지에 워터마크, 텍스트 오버레이 또는 로고가 있습니다.
2. 고객이 받게 될 제품에 포함되지 않은 소품.
3. 메인 이미지의 경우 순백색 이외의 테두리, 프레임 또는 배경을 사용합니다.
4. 이미지 프레임의 85% 미만을 차지하는 제품입니다.
5. 마네킹(의류용) 또는 눈에 보이는 지지 장비.

## photoZseo가 사양을 적용하는 방법

photoZseo 내부의 Amazon 사전 설정은 한 번에 네 가지 작업을 수행합니다.

1. 제품이 캔버스의 85% 중앙에 위치하도록 정사각형 프레임으로 자릅니다.
2. 가장 긴 면의 크기를 2000픽셀로 조정합니다(소스가 더 작은 경우 지능적으로 확대).
3. sRGB, 품질 85(보통 250~450KB)로 깨끗한 JPEG를 작성합니다.
4. 배경 제거가 활성화된 경우 사진에 찍힌 배경을 순수한 #FFFFFF로 대체하고 가장자리를 페더 처리하여 제품이 잘라서 붙인 것처럼 보이지 않습니다.

전체 파이프라인은 전화에서 실행됩니다. 장치에서 아무것도 남지 않습니다.

## 빠른 규정 준수 체크리스트

업로드하기 전에 다음을 확인하세요.

- [ ] 가장 긴 면은 ≥1000px(2000px 권장)
- [ ] 배경이 "white-picker" 테스트를 통과했습니다. 네 모서리는 `#FFFFFF`로 읽혀집니다.
- [ ] 파일이 10MB 미만이며 JPEG로 저장되었습니다.
- [ ] 메인 이미지의 화면 비율은 1:1입니다.
- [ ] 텍스트, 워터마크 또는 프레임 없음

5개를 모두 확인하면 목록은 첫 번째 시도에서 Amazon의 자동 검증을 통과하게 되며 출시 타이밍을 죽이는 앞뒤로 건너뛰게 됩니다.
