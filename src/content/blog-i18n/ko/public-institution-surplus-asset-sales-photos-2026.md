유지되는 방식으로 잉여 자산을 촬영하려면 모든 항목에 대해 동일한 고정 사진 세트를 사용하고, 자산 태그를 프레임에 유지하고, 마모 및 손상을 공개적으로 표시하고, 자산 번호 뒤에 모든 파일의 이름을 지정하십시오. 그런 다음 항목당 하나의 스프레드시트 행을 사용하여 원본을 하나의 아카이브에 보관합니다. 그것이 전체 시스템입니다. 이 가이드의 나머지 부분에서는 학교의 창고 정리, 병원의 장비 폐기, 공공 기관이나 회사에서 스크랩 및 오래된 재고를 판매하는 방법을 보여줍니다.

*최종 확인 날짜: 2026년 11월. 이 가이드는 사진 및 기록에 대한 일반적인 모범 사례입니다. 이는 법률, 세금 또는 조달 관련 조언이 아닙니다. 공공기관, 협회, 재단에 의한 판매는 일반적으로 자체 규정 및 내부 규칙에 따르므로 자체 판매 규칙과 관련 기관 또는 판매 플랫폼의 판매 규칙을 따르십시오. 우리는 여기에 의도적으로 법적 기준이나 절차를 명시하지 않았습니다.*

## 기관의 잉여판매에 다른 사진 접근 방식이 필요한 이유

신제품 판매자가 매력적인 사진을 원합니다. 중고품을 판매하는 기관에는 정직하고 비교 가능하며 추적 가능한 사진이 필요합니다. 이러한 판매를 차별화하는 세 가지 요소가 있습니다.

- 구매자가 먼저 검사할 수 없는 경우가 많습니다. 사진은 점검 모습입니다. 온라인 경매 목록에는 일반적으로 사진이 품목을 정확하게 표현하지 못할 수 있으며 서면 설명이 적용되므로 사진과 설명이 일치해야 한다는 알림이 표시됩니다.
- 누군가가 나중에 판매를 검토할 수도 있습니다. 감사자, 이사회, 검사관 또는 실망한 입찰자는 정확히 무엇이 판매되었으며 어떤 상태로 판매되었는지 물을 수 있습니다.
- 수백 가지 항목, 많은 사진 작가. 규칙 없이는 직원마다 사진이 다르고, IMG_4821.jpg 같은 파일명은 한 달이 지나도 아무 의미가 없습니다.

## 실행된 시나리오(가설)

작업장을 대체하는 직업 학교를 예로 들어 보겠습니다. 작업대와 드릴 프레스부터 사무실 의자, 모니터 30개, 혼합 케이블 팔레트까지 약 400개 품목입니다. 학교에서는 추첨으로 판매하기를 원합니다. 교직원 2명이 오후 2시를 갖고 학교의 전화를 받습니다.

시스템이 없으면 라벨이 지정되지 않은 2,000장의 사진이 남게 됩니다. 하나를 사용하면 다음과 같은 작업을 수행합니다.

1. 자산 번호 라벨이 없는 품목의 경우 자산 번호 라벨을 인쇄하거나 기존 재고 태그를 사용하여 보이는 곳에 부착하세요.
2. 간단한 촬영 장소(빛이 고른 벽이나 바닥)를 설정하고 모든 항목을 동일한 순서로 촬영합니다.
3. 나중에가 아닌 당일에 파일 이름을 바꾸고 정렬하십시오.
4. 자산 번호를 키로 사용하여 항목 또는 로트당 하나의 시트, 하나의 행을 만듭니다.
5. 잘린 사본만 게시하십시오. 원본을 그대로 보관하십시오.

## 사진 목록: 모든 항목에 대해 사진을 찍을 대상

| 사진 | 목적 | 적용대상 |
|---|---|---|
| 1. 개요, 전면 3/4 | 구매자가 품목을 인식할 수 있도록 합니다. | 모든 항목 |
| 2. 프레임 내 자산 태그/시리얼 플레이트 | 기록할 사진 링크 | 하나가 있는 모든 항목 |
| 3. 뒷면 또는 옆면 | 포트, 라벨, 숨겨진 마모 표시 | 장비, 가구 |
| 4. 스케일 참조 | 크기 표시(눈금자 또는 그 옆에 있는 표준 개체) | 크기가 중요한 품목 |
| 5. 각 결함, 클로즈업 | 정직한 상태: 찌그러짐, 녹, 균열, 누락된 부품 | 결함이 있는 모든 품목 |
| 6. 작동 상태(테스트한 경우) | 화면이 켜져 있고 모터가 작동 중이며 시트에 날짜가 기록되어 있음 | 전자, 기계 |
| 7. 부지개요 | 혼합된 로트의 모든 조각을 함께 표시합니다. | 로트, 팔레트 |

품목이 키가 큰 경우를 제외하고 가로 방향으로 사진을 찍습니다. 일광이나 실내 조명을 사용하고 광택이 나는 표면에 플래시가 비치는 것을 피하십시오.

## 상태를 솔직하게 보여주세요: 간단한 등급 척도

짧은 조건 척도를 선택하고 사진 세트와 목록 텍스트 모두에 사용하십시오. 각 레벨을 한 문장으로 정의하여 직원이 동일한 방식으로 등급을 매길 수 있도록 하세요. 예를 들어:

| 등급 | 의미(자신만의 표현) | 사진 필요 |
|---|---|---|
| A | 작동하며 가벼운 화장만 가능합니다. | 개요 + 태그 |
| B | 작동됨, 눈에 띄는 마모 | 개요 + 태그 + 착용 클로즈업 |
| C | 결함이 있거나 불완전한 작업 | 개요 + 태그 + 모든 결함 |
| D | 부품이나 스크랩으로 인해 작동하지 않음 | 개요 + 태그 + 실패 이유 |

위의 규모는 단지 예시일 뿐입니다. 자신의 규칙에 맞게 조정하세요. 핵심은 등급, 설명, 사진이 동일한 내용을 전달한다는 것입니다. 구매자는 실제 물건을 실제 상태로 보아야 하기 때문에 손상된 부분을 편집하지 말고 중고 품목에 배경 제거 또는 강화 도구를 사용하지 마십시오.

## 자산 번호로 파일 이름 지정

파일 이름은 가장 저렴한 컨트롤입니다. 식별자를 먼저 입력하고, 형식을 고정하고, 공백을 사용하지 마세요.

| 예시 파일 이름 | 그것이 당신에게 말하는 것 |
|---|---|
| 2024-0173_개요.jpg | 자산 2024-0173, 주요 사진 |
| 2024-0173_태그.jpg | 신원 증명을 위한 자산 태그 |
| 2024-0173_결함-1.jpg | 첫 번째 결함 클로즈업 |
| LOT-07_개요.jpg | Lot 7, 단체 사진 |
| LOT-07_item-03.jpg | 로트 7 내부의 세 번째 작품 |

이 작업을 유지하는 규칙: 등록부에 표시된 대로 정확하게 재고 번호를 사용하고, 목록이 올바르게 정렬되도록 앞에 0을 유지하고, 소문자 접미사를 사용하고, 숫자를 재사용하지 마십시오. 항목에 자산 번호가 없는 경우 임시 번호(예: TMP-0001)를 생성하고 시트에 기록합니다.

## 시트 1개, 항목당 행 1개

단일 CSV 또는 스프레드시트를 사용하여 사진 세트와 목록을 동기화된 상태로 유지하세요. 최소 열 세트는 다음과 같습니다.

| 열 | 예 |
|---|---|
| 자산 번호 | 2024-0173 |
| 설명 | 기둥 드릴, 230V, 척 키 포함 |
| 상태_등급 | B |
| 결함 | 베이스에 페인트가 벗겨졌습니다. 벨트 커버가 없습니다. |
| 테스트를 거쳤습니다. | 예, 날짜가 기재되어 있습니다 |
| 많이_아니요 | LOT-07 |
| 사진_파일 | 2024-0173_overview.jpg; 2024-0173_태그.jpg |
| 촬영_작성자/날짜 | 이니셜, 2026-11-20 |

파일명과 시트에 자산번호가 모두 포함되어 있어 목록, 판매기록, 아카이브 등을 단 몇 초 만에 대조 확인이 가능합니다. 또한 스프레드시트를 허용하는 모든 플랫폼에서 대량 업로드가 간단해집니다. [대량 CSV 및 XLSX 가져오기](/ko/blog/bulk-csv-xlsx-import-46-marketplaces-2026)와 동일한 생각이 적용됩니다.

## 사진 속 개인 데이터를 보호하세요

기관 공간에는 사진을 찍고 싶지 않은 개인 데이터가 가득합니다. 게시되기 전:

- 배경에 있는 얼굴과 사람: 자르거나 가립니다.
- 차량 및 주차장의 번호판: 출판된 사본에 표시하십시오.
- 문서, 파일, 라벨 및 화이트보드: 환자, 학생, 직원 또는 고객 이름이 눈에 잘 띄는 경우가 많습니다. 가능한 한 사진을 찍기 전에 문서를 제거하십시오.
- 화면 및 하드 드라이브: 화면을 끄세요. 귀하의 IT 정책에 따라 판매 전에 저장 장치를 닦으십시오. 로그인 화면 사진도 보안 문제다.
- 이미지 파일에 포함된 위치 데이터: 휴대폰에서 위치 데이터를 기록하는지 확인하고, 위치 공유를 원하지 않으면 게시된 사본에서 해당 데이터를 제거하세요.

데이터 보호 규칙은 국가마다 다르며(예: EU의 GDPR, 터키의 KVKK) 기관마다 자체 정책이 있을 수 있습니다. 확실하지 않은 경우 데이터 보호 담당자에게 문의하세요. 편집되지 않은 원본은 액세스가 제한된 내부 아카이브에만 보관하세요.

## 감사에도 살아남는 아카이브 구축

감사용 사진 아카이브에는 특별한 소프트웨어가 필요하지 않으며 규율만 필요합니다.

- 판매 또는 로트당 하나의 폴더(날짜 및 판매 참조 이름이 지정됨)
- 원본은 손대지 않았습니다. 별도의 하위 폴더에 게시 가능한 사본.
- 사진 옆에 저장된 시트는 판매가 종료되면 PDF 또는 CSV로 내보냅니다.
- 누가 사진을 찍었고 언제 시트에 기록했는지.
- 보관 기간은 본 조항이 아닌 귀하의 기록 정책에 따라 설정됩니다.
