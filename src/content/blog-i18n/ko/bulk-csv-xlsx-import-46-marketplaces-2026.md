새로운 마켓플레이스에서 판매할 때 가장 어려운 부분은 마켓플레이스가 아닙니다. 모든 제목을 다시 입력하고, 모든 사진을 다시 업로드하고, 모든 열을 다시 매핑하지 않고도 기존 800개 제품을 여기에 가져옵니다.

photoZseo의 대량 카탈로그 가져오기는 왕복을 처리합니다. 이미 가지고 있는 파일을 드롭하면 새로운 플랫폼으로의 전환이 80% 진행된 것입니다.

## 대량 가져오기가 존재하는 이유

Trendyol를 추가하는 Amazon FBA 판매자, TikTok Shop로 확장되는 Etsy 매장, Walmart로 이동하는 Shopify 매장인 경우 카탈로그가 이미 존재합니다. 한 번 내보냈습니다. 문제는 모든 플랫폼이 서로 다른 열 이름, 서로 다른 이미지 사양, 서로 다른 제품 분류 등 약간 다른 스키마를 사용한다는 것입니다. 수동 수정은 새 채널당 몇 시간의 스프레드시트 작업을 수행하는 것입니다.

photoZseo는 이를 몇 분으로 단축합니다.

## 가져오는 항목

가져오기 도구는 다음 네 가지 형식을 읽습니다.

- CSV — Shopify 제품 내보내기, Amazon 플랫 파일 업로드, Trendyol 대량 템플릿.
- TSV — 이전 시스템이나 사내 시스템의 탭으로 구분된 변형입니다.
- XLSX — 다중 시트 카탈로그가 포함된 Excel 파일입니다.
- JSON — API 내보내기 또는 내부 제품 피드.

각각에는 제목, 설명, 가격, SKU, 바코드, 변형 축(크기, 색상), 재고 및 가장 중요한 사진 URL이 포함될 수 있습니다. photoZseo에 있으면 동일한 데이터가 견적, 내보내기 및 SEO 자동 채우기를 구동합니다.

## 41개 플랫폼에서 자동 감지

킬러 기능은 형식 지원이 아닙니다. 자동 감지입니다.

photoZseo는 파일의 열 헤더를 검사하고 이를 알려진 41개의 플랫폼 내보내기 스키마와 일치시킵니다.

- 서부 시장: Amazon, Shopify, eBay, Etsy, Walmart, WooCommerce
- 터키어: Trendyol, Hepsiburada, N11
- 국경 간 아시아: AliExpress, Lazada, Shopee, Temu, SHEIN, DHgate, Made-in-China, Global Sources
- 라틴 아메리카: Mercado Libre, Coupang
- 유럽: Cdiscount, Bol.com, Kaufland, Allegro, Zalando, Fruugo, Jumia
- ...그 외 17개.

파일이 이들 중 하나에서 온 경우 photoZseo는 드롭 시 해당 파일을 인식합니다. 열 매핑 마법사가 없습니다. "이 헤더의 의미는 무엇입니까?"라는 메시지가 표시되지 않습니다. 그냥 작동합니다.

## 사진 URL은 병렬로 가져옵니다.

대부분의 카탈로그 내보내기에는 포함된 이미지가 아닌 사진 URL이 포함됩니다. photoZseo는 여러 연결, 스마트 재시도, 인지 해시 중복 제거 등을 통해 병렬로 다운로드하므로 동일한 제품 사진을 두 번 가져오지 않습니다.

기본적으로 켜져 있는 Wi-Fi 전용 토글이 있습니다. 켜진 상태에서:

- Wi-Fi를 종료하면 다운로드가 일시중지되고 Wi-Fi로 돌아오면 다시 시작됩니다.
- 휴대전화 요금에 놀랄 일이 없습니다.
- 2,000개의 제품을 가져오더라도 데이터 요금제가 소모되지 않습니다.

이 기능을 끄면 photoZseo는 활성화된 모든 연결을 사용하므로 책상 위의 사무실 Wi-Fi에 유용합니다.

## 실용적인 워크플로우

대부분의 판매자가 실행하는 왕복 여행은 다음과 같습니다.

1단계 - 소스 플랫폼에서 내보내기 Shopify, Amazon 또는 Etsy 모두 카탈로그를 CSV/XLSX로 다운로드할 수 있습니다. 그것을 잡아.

2단계 - 파일을 photoZseo에 놓습니다. iPhone에서는 아무 프로젝트에서나 가져오기를 누르세요. iPad의 경우 파일에서 드래그하세요. 자동 감지는 플랫폼을 식별하고 백그라운드에서 사진 URL을 가져오기 시작합니다.

3단계 — [AI가 SEO 필드를 채웁니다.](/features/seo-filenames)를 사용하세요. photoZseo는 국제적으로 판매하는 경우 각 제품의 제목, 슬러그, 메타 설명, 대체 텍스트, 태그 및 키워드를 12개 언어로 작성합니다.

4단계 - 새로운 마켓플레이스로 내보내기 Amazon, Trendyol, Walmart 등 목적지를 선택하세요. photoZseo는 해당 플랫폼의 정확한 열 순서로 파일을 다시 작성하고, 플랫폼 사양에 맞게 이미지 크기를 조정하고, 결과를 단일 ZIP으로 패키징합니다.

5단계 - 새 채널에 업로드합니다. 대상에서 사용하는 대량 업로드 도구에 관계없이 출력 파일이 준비됩니다.

일주일 동안 스프레드시트 작업을 했다면 점심 시간은 30분이었습니다.

## 이것이 국경 간 판매자에게 중요한 이유

홈 마켓플레이스 이상으로 확장하는 데 가장 큰 장애물은 카탈로그 전환 비용입니다. 대부분의 판매자는 Amazon US가 가장 좋기 때문에 Amazon US를 유지하는 것이 아니라 Mercado Libre 또는 Trendyol로 이동하는 것은 카탈로그를 처음부터 다시 구축하는 것을 의미하기 때문입니다.

대량 가져오기 + 46개 마켓플레이스 사전 설정으로 해당 차단 요소가 제거됩니다. 동일한 제품 데이터가 모든 채널에 전달됩니다. 새로운 마켓플레이스는 프로젝트가 아닌 기능 전환입니다.

카탈로그 관리자를 고용하지 않고 전 세계적으로 배송하려는 인디 판매자를 위한 잠금 해제입니다.
