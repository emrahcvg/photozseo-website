Um die Produkte lokaler Hersteller online aufzulisten, benötigt eine Gemeinde drei Dinge, bevor sie eine Kamera benötigt: einen gemeinsamen visuellen Standard, ein Produktinformationsformular, das jeder Hersteller ausfüllt, und eine Dateibenennungsregel. Wenn diese vorhanden sind, können eine Frauenkooperative mit einem Dutzend Einmachgläsern und eine Familienmolkerei mit zwei Käsesorten im selben Katalog erscheinen und wie Teil eines zusammenhängenden regionalen Angebots aussehen. Ohne sie erhalten Sie 40 verschiedene Hintergründe, 40 Benennungsgewohnheiten und Listenseiten, die niemand vergleichen kann.

*Zuletzt überprüft: November 2026. Dies ist ein praktischer Foto- und Auflistungsleitfaden. Es handelt sich nicht um eine Rechtsberatung und es werden keine Verkaufs-, Ausschreibungs- oder Beschaffungsregeln einer Kommune beschrieben. Befolgen Sie Ihre eigene Gesetzgebung. Die Bildregeln auf dem Marktplatz ändern sich. Überprüfen Sie daher die aktuellen Richtlinien der jeweiligen Plattform, auf der Sie ein Produkt auflisten.*

## Was ist das eigentliche Problem in einem Multi-Produzenten-Katalog?

Das folgende Szenario ist hypothetisch, um die Form der Arbeit zu zeigen. Eine Bezirksgemeinde betreibt ein lokales Produktprogramm mit 35 Produzenten: einer Frauenkooperative (Marmeladen, Gurken, getrocknete Kräuter), zwei Honigwächtern, einer Olivenölpresse, einer Handwerksgruppe (gewebte Taschen, Filz) und einigen kleinen Bäckern. Sie wollen eine Online-Präsenz und, falls gewünscht, Listungen auf regionalen oder nationalen Marktplätzen.

Die typischen Ausfälle sind vorhersehbar:

- Jeder Hersteller sendet Handyfotos mit unterschiedlichen Hintergründen und Lichtverhältnissen
- Produktnamen werden auf vier Arten geschrieben („Thymian“, „getrockneter Thymian 50 g“, „Kekik“, „KEKIK 50 GR“).
- Dasselbe Produkt wird auf den Seiten mit unterschiedlicher Gewichtung angezeigt
- Fotos heißen `IMG_2231.jpg` und niemand weiß, wem sie gehören

## Schritt 1: Schreiben Sie einen einseitigen visuellen Standard

Beschränken Sie es auf eine Seite, die ein Genossenschaftsmitglied ohne Schulung verfolgen kann.

| Regel | Standard (Beispiel, an Ihren eigenen anpassen) |
|---|---|
| Hauptbild | Ganzes Produkt, einfacher heller Hintergrund, zentriert, nichts anderes im Rahmen |
| Zweites und drittes Bild | Etikett auf der Rückseite mit Zutaten, Nahaufnahme der Textur oder handwerklichen Details |
| Lifestyle-Bild | Eine, optionale, einfache Einstellung, gleicher Stil für alle Produzenten |
| Licht | Fenster-Tageslicht oder zwei weiche Lampen, kein Blitz |
| Orientierung | Gleiches Seitenverhältnis für alle Hauptbilder (einmal entscheiden) |
| Requisiten | Nur wenn sie die Verwendung erklären (ein Löffel für Honig), niemals eine andere Marke |
| Logos und Texte | Keine hinzugefügten Wasserzeichen; Das Produktetikett zeigt, was es zeigt |
| Retusche | Nur Helligkeit und Zuschneiden korrigieren; Ändern Sie weder Farbe noch Form des Produkts |

Wählen Sie das Seitenverhältnis, indem Sie sich den strengsten Marktplatz ansehen, den Sie verwenden möchten, und behalten Sie dann einen größeren Master bei. Suchen Sie auf der aktuellen Bildseite dieser Plattform nach Zahlen, anstatt sich auf eine Zahl aus einem Artikel zu verlassen.

## Schritt 2: Sammeln Sie Produktdaten, bevor Sie fotografieren

Fotos und Text gehen zusammen schief, wenn sie getrennt erstellt werden. Verwenden Sie ein freigegebenes Blatt (eine Tabellenkalkulation funktioniert).

| Spalte | Warum es wichtig ist |
|---|---|
| Produzentencode | Kurze stabile ID; wird zum Dateinamenpräfix |
| Produktname (lokal und bei Bedarf eine weitere Sprache) | Gleicher Wortlaut auf Fotoetikett, Blatt und Auflistung |
| Nettogewicht oder -volumen | Muss mit der Packung auf dem Foto übereinstimmen |
| Zutaten/Material | Wird für die Auflistung benötigt; Überprüfen Sie auch die Etikettenübereinstimmungen |
| Variante | Geschmack, Größe, Farbe |
| Herkunft / Dorf | Unterstützt die regionale Geschichte |
| Zertifizierungen oder Registrierungen, über die der Hersteller verfügt | Listen Sie nur auf, was der Hersteller dokumentieren kann |
| Fotoeinverständnis für Personen | Ja/Nein, für alle Produzenten- oder Werkstattbilder |

Stellen Sie in einer Auflistung keine Behauptungen auf, die der Hersteller nicht beweisen kann. Ob ein Produkt eine eingetragene geografische Angabe oder einen Bio-Status hat, entscheiden die eigenen Unterlagen des Herstellers, nicht der Katalog.

## Schritt 3: Veranstalten Sie einen gemeinsamen Fototag

Für ein Programm dieser Art ist ein einzelner „Fototag“ pro Bezirk in der Regel effizienter, als jeden Produzenten einzeln zu fotografieren.

1. Stellen Sie einen Tisch in der Nähe eines Fensters mit einem schlichten Hintergrund und einem Stativ auf.
2. Drucken Sie die Fotoliste aus: Vorderseite, Etikett auf der Rückseite, ein Detail, bei Bedarf eines im Einsatz.
3. Halten Sie eine Nummernkarte (Herstellercode) in den ersten Rahmen jeder Charge, damit die Chargen leicht sortiert werden können.
4. Fotografieren Sie die Produkte jedes Herstellers gemeinsam. Halten Sie den gleichen Kameraabstand ein.
5. Führen Sie abschließend noch eine kurze Überprüfung auf einem Laptop oder Tablet durch, bevor der Produzent geht, und fotografieren Sie den Film an Ort und Stelle noch einmal.

Bei Gegenständen, die nicht transportiert werden können, wie z. B. große Kunsthandwerke oder frische Waren, kann ein geschulter Freiwilliger oder Mitarbeiter mit derselben Ausrüstung vorbeikommen.

## Schritt 4: Dateien benennen und organisieren

Eine Benennungsregel spart Stunden später.

| Musterteil | Beispiel |
|---|---|
| Produzentencode | `p014` |
| Produkt | `olive-oil` |
| Größe/Variante | `500ml` |
| Sicht | `front`, `label`, `detail` |
| Vollständiger Name | `p014-olive-oil-500ml-front.jpg` |

Verwenden Sie Kleinbuchstaben, Bindestriche, keine Leerzeichen und keine Sonderzeichen. Ein beschreibender Dateiname ist auch eine kleine Hilfe für Suchmaschinen auf der eigenen Seite.

## Schritt 5: Erstellen Sie Produzentenprofile, nicht nur Produktkarten

Käufer von regionalen Produkten kaufen oft die Geschichte. Halten Sie die Produktbilder einheitlich und tragen Sie die Identität in eine Profilkarte ein:

- Name und Ort des Produzenten oder der Genossenschaft
- eine kurze Geschichte mit zwei oder drei Sätzen
- ein freigegebenes Porträt- oder Werkstattbild
- ein vom Hersteller gewählter Link oder Kontaktweg

Bitten Sie für Personenfotos immer um Ihr Einverständnis und entscheiden Sie mit jedem Produzenten, welche Kontaktdaten veröffentlicht werden.

## Checkliste für die Vorveröffentlichung des Katalogs

- [ ] Einseitiger visueller Standard, der allen Produzenten zur Verfügung gestellt wird
- [ ] Jedes Produkt hat eine Zeile im Merkblatt
- [ ] Gewichte, Namen und Varianten stimmen zwischen Packung, Blatt und Auflistung überein
- [ ] Hauptbilder teilen Verhältnis, Hintergrund und Rahmen
- [ ] Dateinamen folgen der Regel; keine `IMG_`-Reste
- [ ] Einwilligung für alle Personenbilder erfasst
- [ ] Keine unbeweisbaren Angaben (Bio, geschützte Herkunft, Gesundheit) im Text
- [ ] Plattform-Image-Regeln werden auf der Live-Plattform-Seite erneut gelesen
- [ ] Die Rechtsabteilung bestätigte, wie die Gemeinde teilnehmen kann
